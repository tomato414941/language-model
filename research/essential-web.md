# Essential-Web

元のデータは使わない。作った人たちが切り出したデータセットは候補で、まだ調べていない。

EssentialAI/essential-web-v1.0（ODC-By）は24兆トークンの Web データで、文書ごとの分野や品質のメタデータで選り分けて使うためのもの。選り分けるのが私たちになるので、データの中身を選り分けないルールに触れる。

作った人たちが切り出した数学、コード、STEM、医療のデータセットも公開されている。ルールは私たちが選り分けないことなので（2026-10-29 にユーザーが明確にした）、これらは丸ごと使える。カードには、Web から作った既存のデータと比べて、数学は8.0%以内、コードは14.3%上、STEM は24.5%上、医療は8.6%上とある。
