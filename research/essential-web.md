# Essential-Web

候補。まだ調べていない。

EssentialAI/essential-web-v1.0（ODC-By）は24兆トークンの Web データで、すべての文書に分野、ページの種類、品質の点数などのラベルが付いている。作った人たちは、ラベルで条件を決めて文書を選び出して使うことを想定している。その選び出しを私たちがすると、私たちが選り分けることになる。条件を付けずに丸ごと使うならルールには触れないが、丸ごとで使って良いデータかは調べていない。

作った人たちが切り出した数学、コード、STEM、医療のデータセットも公開されていて、これらは丸ごと使える。カードには、Web から作った既存のデータと比べて、数学は8.0%以内、コードは14.3%上、STEM は24.5%上、医療は8.6%上とある。

ラベルで選び出すのは、今のソースが FineWeb-Edu の int_score などで文書を切っているのと同じ種類の作業なので、そちらが許されるかと合わせて決まる。
