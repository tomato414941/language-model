# 借りる GPU

v6 も A100 で学習する。

H100 の bf16 の行列の計算の性能は A100 の約3倍（密な計算で 989 と 312 TFLOPS）。v5 は A100 を1時間 約$0.34 で借りたので、H100 が1時間 約$1 より高いと、速くなっても費用は v5 より高くつく。H100 は FlashAttention-3 が使えるので約3倍より速くなるかもしれないが、測っていない。$1 前後の H100 が見つかったときだけ、測って比べる。

中断されうる GPU（interruptible）は 2026-10-24 に試した。最低の入札額の15%増しで、4090 は数分ごとに中断と再開を繰り返し、H100 は1分で止まったまま戻らなかった。安くなる幅も、4090 と A100 で約30%、H100 で約65%だった。使わない。
