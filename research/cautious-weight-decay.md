# Cautious weight decay

v6 のブロック内の行列には、cautious weight decay（arXiv 2510.12402）をかける（f994a12）。更新がその重みを0に近づける向きのときだけ減衰をかける。強さは学習を通して 0.28 から cos 形で0まで下げる。どちらも nanochat と同じ。

IMU-1 の 7000万パラメータの比較では、NorMuon に足して学習損失が 3.156 から 3.125 になった（AdamW からは合わせて −3.85%）。

0.28 は、v5 の 0.1 を batch-size.md の式で換算した値。nanochat の既定値もたまたま 0.28 だが、学習率の基準が違うので、同じ値だから正しいとは言えない。cos 形で下げるときに 0.28 が良いかは確かめていない。
