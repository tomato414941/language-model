# チェックポイントの平均

v6 は減衰期に160ステップごとに重みを残し（10個）、学習のあとで `python -m pretrain average` で最後の10個を平均する（6e5da42）。学習の費用は増えない。平均したものとしないものの両方を評価して比べる。

- IMU-1（arXiv 2602.02522）は、減衰期に5000ステップおきに残した最後の10個に、あとから EMA（β=0.8）をかけ、ベンチマークの平均が +0.014 になった。
- LAWA（arXiv 2306.03241）は、OpenWebText で 125M の検証損失が 2.963 → 2.917（EMA 2.949、SWA 2.952）、355M で 2.855 → 2.819 になった。学習率が高いほど、残す間隔が広いほど効く、としている。

v6 は LAWA と同じ単純な平均にした。IMU-1 の EMA とどちらが良いかは比べていない。

効くかどうかは分からない。v6 は学習率を1%まで下げる途中の重みを、160ステップ（約1.7億トークン）おきに平均する。LAWA の言う「高い学習率で、間隔を広く」とは逆の条件になる。IMU-1 は減衰期の重みで効いているが、間隔は5000ステップだった。
