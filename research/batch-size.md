# バッチの大きさ

v6 は1回の更新を 1,048,576 トークンにした（v5 は 262,144。8d55a8b）。

nanochat の LOG（2026-02-05）は、Power Lines（arXiv 2505.13738）の「最適なバッチは学習トークン数の 0.383 乗に比例する」を使い、d12 で測った 2^19 から外挿している。その表では、34億〜96億トークンを読むモデルが 2^20 になる。v6 は約84億トークン。

学習率と weight decay は、nanochat の scripts/base_train.py の式で v5 から換算した。

- 学習率はバッチの平方根に比例させる。バッチが4倍なので2倍の 0.0032。nanochat のコメントには、Muon にこれを使うのは「not studied carefully, assumption!」とある。
- weight decay は λ·√(B/B_ref)·(D_ref/D) で、0.1 × 2 × 117.4億/83.9億 ≈ 0.28。学習を通して重みが忘れていく速さを保つための式。
