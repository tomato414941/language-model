# x0/resid lambdas と出力のゼロ初期化

v6 は各層の前で x = resid[i]·x + x0[i]·x0 とする。x0 は最初の層に入った値。注意と MLP の出力の重みは0から始める（5541818）。

初期値、学習率、beta1 は nanochat の今のコードに合わせた。nanochat の LOG（2026-01-11）の時点では、x0 は0から始めていた。nanochat の x0 は正規化した埋め込みだが、v6 は埋め込みを正規化していないので、最初の層に入る値をそのまま使う。

- Marin の nano_arch_ablations：resid lambdas で 1.3156 → 1.3123、x0 を足して 1.3112。
- nanochat の LOG（2026-01-11）：x0 はどの深さでも下がった（d8 で −0.0103、d20 で −0.0039）。resid は、x0 の100分の1の学習率でないとうまくいかない。
- nanochat の LOG（2026-01-19〜22）：x0 の beta1 を 0.96 にすると、d20 で −0.0007。0.98 では +0.0033 と大きく悪くなった。

出力のゼロ初期化だけを比べた結果は見つけていない。nanochat がこの形を使っている、というだけ。
