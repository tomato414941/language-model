# v5 から引き継いだもの

v6 は次の仕組みを v5 からそのまま使っていて、v6 のために見直してはいない。ここには、v6 の調査の途中で見つかった結果だけを書く。

- SwiGLU：nanochat の LOG（2026-02-05）では、パラメータと計算量をそろえた ReLU² と比べて、d12 と d24 のどちらでも、ステップ、時間、計算量のすべてで悪かった。Marin の nano_arch_ablations では、ReLU² にしても 1.3156 のまま変わらなかった。v6 で替えるかは決めていない。
- QK-norm：IMU-1（arXiv 2602.02522、7000万パラメータ）で学習損失 −0.63% と、単独では一番効いた。Marin では 1.3160 → 1.3156。
- ヘッドごとの注意のゲート：IMU-1 では単独で −0.05% だった。ただし、QK-norm、value residual、LayerNorm scaling と合わせると −1.64% で、それぞれの和より大きかった。Marin では 1.2827 → 1.2787。
- 文書の中だけで注意を計算すること：nanochat の LOG（2026-01-13、d16）では BPB が 0.85427 → 0.85407 とほとんど変わらず、取り入れていない。Smol Training Playbook の読書ノートには、短い文脈では効果が小さいが、4k〜64k の長い文脈では学習の速さと安定に欠かせなかった、とある。
