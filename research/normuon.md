# NorMuon

v6 のブロック内の行列は NorMuon（arXiv 2510.05491）で更新する（f994a12）。torch の Muon を継承し、手順は nanochat の nanochat/optim.py に合わせた。

直交化した更新の2乗平均を、ニューロン（行か列）ごとに移動平均で持ち（beta2 0.9）、その平方根で割る。そのあと、全体の大きさを直交化した直後のものに戻す。更新の大きさが Muon と同じなので、match_rms_adamw の学習率がそのまま使える。

IMU-1（arXiv 2602.02522）の 7000万パラメータの比較では、学習損失が AdamW の 3.250 から NorMuon で 3.156（−2.88%）になった。
