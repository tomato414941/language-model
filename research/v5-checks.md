# v5 の結果について調べたこと

2026-10-28 に、v5 の事前学習のあとで調べた。

## JCommonsenseQA だけが v4 より下がった（0.426 → 0.390）

ぶれと判断し、指示学習を止めなかった。

- ほかの日本語の評価は v4 より上がっていた。JNLI 0.464 → 0.542、KUCI 0.409 → 0.421、XWinograd 0.558 → 0.572。
- 同じ400問で、stable 段階の最後と decay 段階の最後を比べた。正解率は 0.433 → 0.408、正解の選択肢の BPB は 1.009 → 0.766 と大きく良くなった。正解率の差は10問ぶんで、片方だけが正解した問題は58問と48問だった。
- この比較は400問の抜き出しで行った。今は、抜き出しをモデルの比較の根拠には使わない。また、JNLI はこの大きさのモデルでは当てにならないと、win1 が後で調べている。

## SFT のデータの Nemotron v2 日本語

残すことにした。

- 学習で予測させる日本語側のトークン約1.1億のうち、約18%（約2000万）を占める。
- その約86%は、DeepSeek-R1 が書いた英語の思考で、翻訳を通っていない。訳が崩れうるのは日本語の答えの部分で、日本語側全体の約2.5%。
- 外すと、日本語で思考する手本がなくなる。
- 他のモデルが書いた文章なので、蒸留を禁じるルールとの関係は決まっていない（english-web-data.md の Nemotron-CC と同じ問題）。
