# 評価

## 決まり

- 公開されて広く使われている評価だけを使う。独自の評価は作らない。
- 全問を評価する。
- 使う道具は lm-evaluation-harness と llm-jp-eval v2.1.5。課題は `configs/pretrain-v6.toml` の `evaluation` にある。
- 評価の問題は学習データから除く。

## 問い方

- 事前学習の後のモデルは、続きを書かせる形で問う。
- 指示学習の後のモデルは、同じ形に加えて会話形式でも問う。IFEval と M-IFEval-Ja は会話形式だけで問う。
- 比較は同じ問い方どうしで行う。
- M-IFEval-Ja は、llm-jp-eval の既定（最初の空行まで）と返答全体の両方で採点する。

## 読むときの注意

- M-IFEval-Ja は172問しかなく、同じ重みでも .163 と .186 に揺れた。.03 程度の差は読めない。
- llm-jp-eval の M-IFEval-Ja は、strict も loose も複数の指示の最初しか見ないようにコードが読める（44問。実行して確かめてはいない）。他の人の点と比べるときは注意する。
- v6 は選択肢を記号で答える学習をしたので、KUCI と JMMLU の llm-jp-eval の点は、形式を覚えただけでも上がる。知識の伸びは、選択肢の文の確率を比べる点で見る。
