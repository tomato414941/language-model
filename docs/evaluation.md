# 評価

## 決まり

- 公開されて広く使われている評価だけを使う。独自の評価は作らない。
- テストは提供者が定めた形式で行う。モデルの性能に合わせて形式を変えない。点が低くて差がつかないときは、他の人が提供しているもっと簡単なテストを足す。
- 間違っていると確かめた測り方は、過去と比べられなくなっても切り捨てる。
- 全問を評価する。
- 使う道具は lm-evaluation-harness と llm-jp-eval v2.1.5。課題は `configs/pretrain-v6.toml` の `evaluation` にある。
- 評価の問題は学習データから除く。

## 問い方

- 事前学習の後のモデルは、続きを書かせる形で問う。
- 指示学習の後のモデルは、同じ形に加えて会話形式でも問う。IFEval と M-IFEval-Ja は会話形式だけで問う。
- 比較は同じ問い方どうしで行う。
- M-IFEval-Ja は、公式の採点コードと同じく返答全体で採点する。llm-jp-eval の既定（最初の空行まで）の点は使わない。

## 読むときの注意

- M-IFEval-Ja は172問しかなく、同じ重みでも .163 と .186 に揺れた。.03 程度の差は読めない。
- llm-jp-eval の M-IFEval-Ja は、strict も loose も複数の指示の最初しか見ないようにコードが読める（44問。実行して確かめてはいない）。確かめて本当なら、公式の採点コードに替える。
- v6 は選択肢を記号で答える学習をしたので、KUCI と JMMLU の llm-jp-eval の点は、形式を覚えただけでも上がる。JMMLU だけで日本語の平均が約 .03 上がる見込みなので、報告にはその分を添える。

## 合格の線

結果を見る前に決めた。

- **費用：** データ準備から指示学習と評価までが、v5 の約$21.7 より少ない。試しは含めず、指示学習は選んだ1本だけを数える。
- **点：** 指示学習の後のモデルを v5 の同じ段階（`results.md`）と同じ問い方で比べ、日本語の課題の平均と英語の課題の平均が両方上がる。v5 は日本語 .237、英語 .356。
- **平均に入れる課題：** v5 と v6 の両方で公開の形式で測る課題すべて。日本語は JCommonsenseQA、xWinograd、JNLI、JSQuAD、MGSM と、llm-jp-eval で問う KUCI、JMMLU、M-IFEval-Ja（返答全体の strict）。この3つの v5 の点は .2425、.004、.209。英語は `results.md` の12課題。
- **下がる課題：** 標準誤差の2倍を超えて下がる課題がない。

## 指示学習の2本から選ぶ

学習率 0.00016 と 0.0006 の2本のうち、合格の線の2つの平均の和が高い方を v6 とする。同じ問題で選んでから v5 と比べるので、比較は少し甘くなる。
