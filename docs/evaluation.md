# 評価

## 決まり

- 公開されて広く使われている評価だけを使う。独自の評価は作らない。
- テストは提供者が定めた形式で行う。提供者は、評価の手順を定めていればテストの作者、定めていなければ広く使われている公開の道具とする。モデルの性能に合わせて形式を変えない。点が低くて差がつかないときは、他の人が提供しているもっと簡単なテストを足す。
- 間違っていると確かめた測り方は、過去と比べられなくなっても切り捨てる。
- 全問を評価する。
- 使う道具は lm-evaluation-harness と llm-jp-eval v2.1.5。課題は `configs/pretrain-v6.toml` の `evaluation` にある。各課題と提供者の定めの照合は `research/experiments/test-forms.md` にある。
- 評価の問題は学習データから除く。

## 問い方

- 事前学習の後のモデルは、続きを書かせる形で問う。
- 指示学習の後のモデルは、同じ形に加えて会話形式でも問う。IFEval と M-IFEval-Ja は会話形式だけで問う。
- 比較は同じ問い方どうしで行う。
- MMLU は、作者の形式（5例を付けて記号で答える）で問う。続きの形（OLMES）は、より簡単なテストとして別に測る。
- M-IFEval-Ja は、保存した返答を公式の採点コードで採点する。llm-jp-eval の既定（最初の空行まで）の点は使わない。

## 読むときの注意

- M-IFEval-Ja は172問しかなく、同じ重みでも .163 と .186 に揺れた。.03 程度の差は読めない。
- llm-jp-eval の M-IFEval-Ja は、strict も loose も複数の指示の最初しか見ないようにコードが読める（44問。実行して確かめてはいない）。公式の採点コードの点と比べて確かめる。
- v6 は選択肢を記号で答える学習をしたので、KUCI と JMMLU の llm-jp-eval の点は、形式を覚えただけでも上がる。JMMLU だけで日本語の平均が約 .03 上がる見込みなので、報告には JMMLU を除いた平均を添える。
- JNLI は常に中立と答えると .555 になり、v5 はどの段階でもこれを超えていない。JCommonsenseQA は指示学習の後に1番目の選択肢へ寄る。どちらも点の動きが答えの偏りで説明できることがあるので（`research/experiments/v5-answer-patterns.md`）、報告には JNLI の正解ごとの点と JCommonsenseQA の正解の位置ごとの点を添える。

## 合格の線

結果を見る前に決めた。

- **費用：** データ準備から指示学習と評価までが、v5 の $30.97 より少ない。試しは含めず、指示学習は選んだ1本だけを数える。
- **点：** 指示学習の後のモデルを v5 の同じ段階（`results.md`）と同じ問い方で比べ、日本語の課題の平均と英語の課題の平均が両方、読める差（日本語 .013、英語 .009）を超えて上がる。基準は v6 と同じ文脈の 8k 版で、日本語 .242、英語 .354。この2つは、本番の後の測り直しで MMLU の作者の形式と M-IFEval-Ja の公式の採点を入れた値に置き換わる（日本語の .242 の M-IFEval-Ja は llm-jp-eval の既定の .157）。
- **平均に入れる課題：** v5 と v6 の両方で提供者の形式で測る課題すべて。日本語は JCommonsenseQA、xWinograd、JNLI、JSQuAD、MGSM、KUCI、JMMLU、M-IFEval-Ja（strict）。英語は `results.md` の12課題と MMLU の作者の形式。
- **下がる課題：** 2つのモデルの差の標準誤差の3倍を超えて下がる課題がない。2倍だと、何も変わっていなくても約4割の確率でどれかが超える（`research/experiments/readable-differences.md`）。

## 指示学習の2本から選ぶ

学習率 0.00016 と 0.0006 の2本のうち、合格の線の2つの平均の和が高い方を v6 とする。同じ問題で選んでから v5 と比べるので、比較は少し甘くなる。
