# 結果

## 世代ごとの費用

| 世代 | 読んだトークン | 費用 | 備考 |
|---|---|---|---|
| v5 | 約117億 | $30.97（8k 版） | ゼロから |
| v6 | 約84億 | 約$18.6 | ゼロから。データ準備を含む |
| v7 | 約94億 | 約$33.2 | ゼロから。指示学習のやり直しを含む |

v5 の額は Vast の請求で、8k 版は事前学習 $28.71（A100 を61.8時間）と指示学習 $2.26。文脈を 32,768 トークンに伸ばした 32k 版は、事前学習に $5.86（長い文脈の学習と指示学習）を足した $34.58。データ準備はどちらにも入っていない。

v6 の額は Vast の請求から集計した。データ準備が $0.69、事前学習と選んだ指示学習とその評価が $17.69、後の評価が約 $0.26。選ばなかった指示学習とその評価の約6.1時間分（$2.45）は引いた。そのうち学習の時間は記録がなく、選んだ方と同じ長さと仮定した。

v7 の額は、job-runner の台帳にある時間と時間単価から出した（請求ではない）。事前学習から1回目の指示学習と評価までが $26.62（45.2時間）、準備と試運転が $2.61、指示学習のやり直しが $4.01。

## v5〜v7 の点

`evaluation.md` の定義で v5〜v7 を測った。v5 は文脈 8,192 の 8k 版。v7 の指示学習は、事前学習の Hyperball の率を受け継いでやり直したもの。

2026-11-15 に測った（RTX 5090。前の指示の測定と合わせて $2.36）。

| 比べたもの | 改善の率 | 標準誤差 |
|---|---|---|
| v7 と v5 | +0.75% | 0.17% |
| v7 と v6 | +3.58% | 0.13% |
| v6 と v5 | −2.98% | 0.13% |

どの差も標準誤差の2倍を超える。良い順に v7、v5、v6。

### 日英の釣り合い（balance-ja-en-1、事前学習の後）

FLORES+ の devtest の1,012文を日英で1文ずつ読ませ、日本語の bits を英語の bits で割った値。1より大きいほど、同じ内容に日本語のほうが bits を使う。2026-11-16 に測った（RTX 5090、$0.33）。

| 文 | v5 | v6 | v7 |
|---|---|---|---|
| 全1,012文 | 1.092 ± 0.005 | 1.084 ± 0.006 | 1.075 ± 0.005 |
| どの世代の学習データにもなかった898文 | 1.083 ± 0.006 | 1.075 ± 0.006 | 1.070 ± 0.006 |

v5〜v7 のコーパスには devtest の英語の文が入っていた（v5 96文、v6 26文、v7 36文。日本語は0）。学習で見た英語の文は安く読めるので、全文の値は 0.005〜0.009 大きく出る。898文で、v5→v6 は −0.008 ± 0.002、v6→v7 は −0.005 ± 0.003、v5→v7 は −0.013 ± 0.003。差が縮んだのは、v5 から v7 で日本語の bits が0.9%、英語の bits が2.2%増えたため。

### 指示に従う力（instructions-ja-en-1、指示学習の後）

すべての指示に従った問いの割合（strict）。2026-11-17 に、BenchMAX の問い（IFEval の429問と、同じ問いの日本語）で測り直した（RTX 5090、$1.31）。

| 比べたもの | 改善の率 | 標準誤差 | 英語だけ | 日本語だけ |

v7 と v5、v7 と v6 の差は、全体でも言語ごとでも標準誤差の2倍を超える。v6 と v5 の差は全体では読めず、英語だけで読める。日本語だけの標準誤差は12〜16%。

どのモデルも、返答を他の問いに付け替えたときの点（英語 .10〜.11、日本語 .12）より全体で読める差だけ高い。日本語だけでその差が読めるのは v7 だけ。

前の M-IFEval の172問では、日本語は .174、.140、.140 で、v7 は v5 を上回らなかった。M-IFEval は日本語に特有の指示（です・ます調で書く、など）を含み、BenchMAX は英語と同じ種類の指示を日本語で問う。
