判定は不合格。

- v5 に対して：英語の平均は .017 上がって読める差を超えたが、日本語の平均は .007 下がった。BLiMP が落ちすぎた（.022 下がり、限度は .007）。
- v6 に対して：英語の平均は .022 上がったが、日本語の平均は .050 下がった。KUCI、JMMLU、JNLI が落ちすぎた。
- KUCI と JMMLU：v6 の指示学習のデータには、この2つと JCommonsenseQA、JAQKET の学習用の問題に記号だけで答える会話（約10万5千）が入っていた。点を当て推量の率まで上げるだけで力を示さないため、v7 のデータからは外した。v7 は会話形式でこの2つに選択肢の外の答えを返し、v5 と同じくほぼ0点になる。この2つを除くと、v6 に対する日本語の平均は .018 上がる。
