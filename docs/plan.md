# 計画

## 目標

日英のモデルをゼロから作り、世代を重ねて良くする。新しい世代は、前の世代より少ない費用で、公開ベンチマークの点が前の世代より高いことを目指す。費用には試しの分を入れない。

## 今の世代：v6

モデルの形と学習の組み立ては `configs/model-v6.toml`、`configs/model-v6-patch.toml`、`configs/pretrain-v6.toml` にある。

| 工程 | 状態 | 費用 |
|---|---|---|
| データ準備 | コーパスを作成中。指示学習のデータは R2 に置いた | 約$0.7 の見込み |
| 事前学習、指示学習、評価 | 手順は書いた。未実行 | 約$15 の見込み |

費用の見込みは、RTX 4090 で測った速さ（`research/experiments/v6-throughput.md`）から計算した。全体で約39時間かかる。

## 次にやること

1. データ準備を終え、R2 に届いたことを確かめる。
2. 下の「決まっていないこと」を決める。
3. 本番を流す。動いたことを機械の中で確かめてから、終了時に機械を消す監視を付ける。
4. 結果を `results.md` に書き、合格の線と比べる。

## 決まっていないこと

- 合格の線（`evaluation.md` に案がある）
- 形を 1024×32 のままにするか、1152×24 にするか（`candidates.md`）
- 中断されうる GPU を使うか（`candidates.md`）
- 指示学習の学習率を3通り比べるか（`candidates.md`）

## 進め方

- 機械は借りたら中に入って動いていることを確かめる。止まったら機械を残し、中を調べて続きから直す。
- できた部分から順に R2 に送る。
- 決めたことと分かったことは、そのコミットでこの `docs/` に反映する。
