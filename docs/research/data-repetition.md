# 質の高いデータの繰り返し

同じデータを何回か繰り返して読む。

- Fang ら（arXiv 2503.07879）：学習の設定を適切に変えれば、厳しく選んだデータを10回まで繰り返すほうが、その10倍の量を1回読むより良かった。計算量を何桁も変えても同じだった。
- MiniMax-01（arXiv 2501.08313）：質の低いデータは2回を超えると大きく悪くなり、質の高いデータは4回まで効いた。
- Xue ら（arXiv 2305.13230、2023年）：繰り返すと過学習で悪くなる。悪くなり方には、データの量、モデルの大きさ、学習の目的が大きく効き、データの質の影響は小さかった。正則化はほとんど効かず、dropout だけがよく効いた。
