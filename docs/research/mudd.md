# MUDD

残差の接続の代わりに、それまでの層の出力を、位置ごとに動的に作る重みで混ぜる。query、key、value、残差の入力ごとに重みを分ける。

[MUDDFormer の論文](studies/muddformer.md)は、1.8〜2.4倍の計算量で学習したときと同じ性能になるとしている。

modded-nanogpt の記録 #81 は、最後の2層だけに入れて 1480 → 1415 ステップ（時間は約3%減）。[記録 #92](studies/modded-nanogpt-anvil2.md) で外して測ると、時間は 0.51 秒減り、損失は 6.1 ミリナット悪くなる。論文の主張より小さい。
