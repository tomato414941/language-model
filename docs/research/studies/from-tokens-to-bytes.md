# From Tokens to Bytes

Cartesia の記事 From Tokens to Bytes I・II（2026-10-28、cartesia.ai/blog/from-tokens-to-bytes-part-1、part-2）。H-Net の改良版と、BPE の Transformer を比べている。改良版は公開されていない。

計算量をそろえて、語彙128k、1トークン約4.57バイト、2.2億〜26億パラメータの BPE の Transformer と比べた。データは英語70%、コード20%、数学5%、多言語5%（バイト数）。

- 同じ損失に届く計算の効率は、検証で1.28倍、Paloma で1.83倍、OLMES で2.06倍。
- コードでは、学習に入っている15言語で中央値2.04倍、入っていない10言語で中央値3.10倍。
- 2段の H-Net（36.7億パラメータ）は、SmolLM3（30.8億）の最終の平均点に、約11兆トークンではなく約1兆トークンで届いた。
- 切れ目を別に学習したバイトのモデルのエントロピーで決める形は、OLMES までの効率で H-Net より1.84倍悪い。
- 区切らずに学習した BPE は6.03倍に圧縮し、区切った BPE の4.57倍より圧縮は良いが、同じ損失に届く効率は区切った BPE のほうが1.5倍良い。
- 中国語は BPE より圧縮が弱く、まとまりあたりのバイト数は BPE のトークンの0.43倍。日本語の数字は本文にない。

比べているのは計算量とデータの量で、時間は書かれていない。
