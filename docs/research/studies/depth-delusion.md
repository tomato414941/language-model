# The Depth Delusion

Fahim、Karim、The Depth Delusion: Why Transformers Should Be Wider, Not Deeper（arXiv 2601.20994、2026-01）。査読前。

幅ごとに限界の深さがあり、それを超えると、パラメータが増えても損失が上がると主張する。限界は幅の0.44乗に比例するとし、2.43·ln(幅) で近似している（幅512で15.2層、1024で16.9層、1536で17.8層）。最適な深さは計算量の0.12乗、最適な幅は0.34乗で増えるので、幅を深さの2.8倍の速さで増やすべきだとしている。理由として挙げるのは、深いほど手前の層に勾配が届かなくなること。結論では「D≈2.5·log W を超えない」ことを勧めている。

30の形を SlimPajama で学習した。GPT-2 のトークナイザ、AdamW、ピーク学習率 3e-4、weight decay 0.1、256列×1024トークンのバッチ、標準の Pre-LN。6億以下の18の形は6.4Bトークンに固定し、約10億以上の12の形は最大140Bトークンまで学習した。

| 大きさ | 幅×層と損失 |
|---|---|
| 1億〜1.5億 | 512×16 3.435、512×24 3.468、512×32 3.441 |
| 約11億〜12億 | 2560×12 2.847、1792×24 2.821、1280×48 2.839、1152×64 2.897、1024×80 2.978 |
| 約30億 | 3840×16 2.553、3072×24 2.534、2432×40 2.519、2176×56 2.585、1792×72 2.681 |
| 約70億 | 4096×32 2.298、2816×64 2.417 |

読むときに気をつけること。

- 深さに応じた補正を入れていない。著者も、ReZero などの安定化で限界は上に動きうるとしている。
- シードは1つで、損失は学習中の交差エントロピーを検証の代わりに使っている。
- 6.4Bトークンの比較は大きさによらずトークン数が同じなので、1パラメータあたりのトークン数は形ごとに違う。
- 幅1024で測ったのは2、8、16、80層だけで、16層の次は80層まで測っていない。
- 幅512の U 字は差が0.03ほどで、損失は24層より32層のほうが低い。
- 70億の2つのモデルのパラメータ数が、6.86Bと6.38Bの箇所と、6.92Bと7.08Bの箇所で食い違う。
