# The Depth-to-Width Interplay in Self-Attention

Levine ら（arXiv 2006.12467）。

自己注意のネットワークで、深さが効く領域と効かない領域の切り替わりが、幅によって決まることを理論で予測し、6〜48層の実験で確かめた。与えられたパラメータ数での深さと幅の配分を、数で示している。

- 6層を超えると、損失はパラメータ数でほぼ決まり、幅と深さの比によらないという先行研究の見方には、この切り替わりが隠れているとしている。
- GPT-3 の 10B までの形は、大きさのわりに浅すぎる。175B は逆に深すぎる。
- 1T パラメータでは、幅3万が最適と予測している。

読んだのは要旨、導入、結論まで。Gemstones の説明によると、大きいモデルでは最適な深さは幅の対数で増える。
