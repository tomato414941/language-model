# Scaling Laws for Neural Language Models

Kaplan ら（arXiv 2001.08361）。

パラメータ数、データ、計算量を増やすと、損失はべき乗で下がる。文脈は基本1024、1回の順伝播の計算量は C ≈ 2N + 2·層·文脈·幅（N は埋め込みを除くパラメータ数）。

形の影響はとても小さいとしている。パラメータ数をそろえて幅と層を変えると、損失の差は広い範囲で数%にとどまり、幅÷層を40倍変えても少ししか変わらない。(層, 幅) = (6, 4288) の損失は (48, 1600) の3%以内。

CompleteP（arXiv 2505.01618）は、この実験の設定では深いモデルが不利だったと指摘している。

読んだのは、計算量の式と形についての節だけ。
