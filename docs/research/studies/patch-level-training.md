# Patch-Level Training

Shao、Meng、Zhou、Beyond Next Token Prediction: Patch-Level Training for Large Language Models（arXiv 2407.12665、ICLR 2025）。実装は GitHub の shaochenze/PatchTrain。

連続する K トークンの埋め込みを平均して1つのパッチとし、次のパッチの K トークンを予測させる。学習データの割合 λ をこの形で読み、残りを普通のトークン単位で読む。切り替えのときに引き継ぐのは重みだけで、オプティマイザと学習率のスケジュールはやり直す。費用は元の λ/K + 1 − λ 倍になる。

条件は The Pile 360B トークン、LLaMA 系の形、語彙32000、AdamW（学習率 3e-4、cosine）、weight decay 0.1、バッチ 2M トークン。文脈はトークン単位で2048、パッチ単位で K×2048。

K=4 の結果。PPL は WikiText-103、平均は MMLU、HellaSwag、PIQA、WinoGrande、ARC-E、ARC-C のファインチューニングなしの正解率。

| モデル | λ | 費用 | PPL | 平均 |
|---|---|---|---|---|
| 370M | なし | 1.0× | 10.9 | 42.2 |
| 370M | 1/2 | 0.625× | 10.6 | 42.9 |
| 370M | 2/3 | 0.5× | 10.7 | 42.5 |
| 370M | 4/5 | 0.4× | 11.0 | 42.1 |
| 780M | なし | 1.0× | 9.2 | 45.5 |
| 780M | 2/3 | 0.5× | 9.1 | 46.3 |
| 1.3B | なし | 1.0× | 8.2 | 48.5 |
| 1.3B | 2/3 | 0.5× | 8.2 | 49.0 |
| 2.7B | なし | 1.0× | 7.1 | 53.1 |
| 2.7B | 2/3 | 0.5× | 7.2 | 53.5 |

- 指示学習のあとの MT-Bench は、モデルによって上下し、差は普通のばらつきの範囲だとしている。
- K=2 と K=4 の損失の曲線はほとんど同じで、K=8、16 では少し悪くなる。
- パッチ単位の文脈を K×2048 から2048に縮めても、370M（λ=1/2）では PPL +0.06、正解率 −0.2 にとどまり、基準を上回ったまま。
- 同じ 360B トークンを読むなら、6エポックに分けたパッチ単位の学習のほうが、1エポックより良かった。
- 8台の A100 での実際の速さは、K=4、文脈8192で約3.8倍。
- K と λ の一般的な法則は見つかっていないとしている。

Muon 系のオプティマイザと組み合わせた公開の結果は見つけていない（2026-10-31 に調べた）。
