# Context Language Models

Context Language Models（arXiv 2609.37725、2026-09）。

文脈をファイルとして扱い、モデルがそれを自由に書き換える。文脈の管理を、外の仕組みからモデル自身の振る舞いに移す。

既存のモデルをそのまま使って、BrowseComp-Plus で正解率 +11.4%、計算 −21.5%、12時間の EdgeBench で点 +5%、計算 −59%、24時間の複数リポジトリの課題で同じ計算のまま改善が65%大きくなったとしている。自然言語の指示を最適化すると、文脈管理の課題で正解率が最大35.9ポイント上がる。

配信側の Suffix Cache Reuse でサーバーの計算が35%減る。Qwen3.5-9B での強化学習は 28.8% → 42.5% で、H200 64枚を使っている。

比べている課題の一部（ContextBench）は著者が作ったもので、FLOPs は理論値。効果はモデルの力に左右されるとしている。
