# Why We Build Local Large Language Models

Saito ら（arXiv 2412.14471）。日本語、英語、多言語の35のモデルを、日英19の課題で比べた観察研究。要旨、関連研究、結論と、課題の相関、主成分分析の説明を読んだ。

- 英語の点と日本語の点の相関は、学校の科目（MMLU と JMMLU）が 0.91、算数（GSM8K と MGSM）が 0.94、コード（HumanEval と JHumanEval）が 0.98。著者らは、これらを伸ばすために日本語のデータを使う強い理由はないと書いている。
- 日本についての知識の質問（JEMHopQA、NIILC）と英日翻訳は、日本語のテキストで学習すると伸び、日本語のテキストの計算量に比例して伸びる。
- JCommonsenseQA と JSQuAD は、この日本語の能力の成分への寄与が小さい。

モデルどうしの相関で、データを変えて比べた実験ではない。ある課題が英語のデータで伸びるとは、直接には言っていない。
