# Sampled softmax

学習の損失を語彙全体ではなく、候補の集合の中で計算する。候補には、そのバッチの正解をすべて入れ、残りを順に回して足す。出力の層の計算が減る。

[modded-nanogpt の記録 #92](studies/modded-nanogpt-anvil2.md)では、語彙50304に対して候補を10240から24576へ増やし、学習の約93%で使い、最後は語彙全体に戻す。検証はいつも語彙全体。学習の勾配には偏りが入るとしている。74秒から40秒への短縮のうち、損失の計算のほかの変更と合わせて約8秒がこの分だった。

出力の層の計算の割合が大きいモデルほど効く。
