# 出典のメモの数字の照合

2026-10-31 に、`sources/` のメモの数字を原文と照らし合わせた。

小数と3桁以上の数を取り出して、原文のテキストにあるかを機械的に調べ、見つからなかったものを目で確かめた。

- 原文の図から読み取った値（CompleteP の表）は、図と見比べた。
- 単位を変えた値（1.34億と 134M、73.9秒と分の表記など）と、四捨五入した値（LLM-jp-4 の効果量）は、元の値を確かめた。
- 誤りは2つ見つかった。語彙の研究（`sources/large-vocabulary.md`）の表で、1つの値が抜けていた。選好の最適化の数字は、原文にも読書ノートにも見つからなかったので外した。

この照合は、数字が原文に存在することを確かめるもので、数字がどの条件の値かまでは確かめていない。意味まで読み直したのは、学習の設定の根拠にしている次の部分だけ。

- Patch-Level Training の費用と点
- IMU-1 の学習率の下げ方（20%が最良、1-sqrt）と EMA の +0.014
- Straight to Zero の結論
- LAWA の検証損失
- Chinchilla の 70B と 1.4T
- Power Lines と nanochat のバッチの表
- nanochat の FP8、SwiGLU、幅と層、ヘッドの幅
- LLM-jp-4 の中間の学習の候補の表と SFT の学習率
- FinePhrase の表
