# 層を足して大きくする試し（2026-10）

continue-v4 の 115M のモデルを、安定期の終わりから同じ費用で2通りに続けて比べた（`configs/probe-growth.toml`）。同じ新しい文書を同じ順で読ませた。

- そのまま：25,000 更新（`configs/bilingual-v4-extend.toml`）
- 層を2倍にしたもの：足した層の出力を0から始め、元と同じ予測から始める（LLaMA Pro の形、`pretrain grow`）。1更新の費用が約2倍なので 12,500 更新（`configs/bilingual-v4-grown.toml`）

どちらも更新の最後の5分の1で学習率を下げ、減衰期のコーパスを読んだ。

| | そのまま | 層を2倍 |
|---|---|---|
| 検証の bits per byte（日、英） | 0.8703、1.0399 | 0.8738、1.0446 |
| HellaSwag（acc_norm） | .3056 | .3053 |
| JCommonsenseQA | .4611 | .4513 |
| JNLI | .4347 | .5053 |
| BLiMP | .7664 | .7764 |
| SciQ（acc_norm） | .658 | .664 |

検証の損失は、層を足した方がわずかに悪い。課題の点は、課題によって上下し、全体として差はない。同じ費用なら、層を足しても得にならなかった。
