# v6 の学習データを読む

2026-11-01 に、R2 の v6 のコーパスから範囲読み取りでランダムな窓を取り出し、文書に戻して読んだ。文書の中身は変えていない。パッチ、安定期、減衰期の日英で各120窓（4,096トークン）、日本語のパッチと安定期で各500窓を追加し、指示学習は日英で各40行を読んだ。読んだのは全体のごく一部で、機械的な数え上げと、数十の文書を目で読んだ範囲。

## 問題がなかったこと

- 各出典のトークン数は、混ぜ方の目標と 0.1% 以内で合う。
- 文書の始まりと終わりの印は釣り合い、文書の中に特殊トークンは混ざっていない。
- 日本語の文書に日本語がほとんどないものは 0〜0.4%。英語の文書に日本語の文字が2%以上あるものは 0.2〜1.3%。
- 置換文字を含む文書は減衰期の英語の 0.3% だけ。同じ行が3割を超える文書はなかった。
- 指示学習の行は、役割の印、思考の印、終わりの印が揃っている。記号で答える問題も入っている。

## 分かったこと

コーパスのファイルは、混ぜ方の順に出典ごとに並んでいる（`write_corpus`）。日本語では、コードらしい文書のトークンがファイルの最後の1割に集まり、そこで .54〜.59、他の位置ではほぼ 0 だった。

学習は窓の順番をランダムにするので、出典の順には読まない。更新あたりの出典の割合は、期待値では混ぜ方どおりになる。ただ、1つの窓の中はほぼ同じ出典になる。v5 も同じ作り。効果は測っていない。

日本語の減衰期は、文書の43%が「Q:」で始まる LLM が書いた問答だった（混ぜ方では日本語の44%が llm-jp の出典）。読んだ範囲に事実の誤りがあった（1976年に5代目シビックが発表された、正多角形の内角の和は360度である、など）。細かいフィルタをしない決まりなので除いていない。点への影響は分からない。

少数だが、次のものも見つけた。パッチの日本語に「user:」「assistant:」が文字のまま残る文書（1回目の標本で235文書中8、2回目の894文書では0）。減衰期の英語に `<think>` が文字のまま残る文書（309文書中11）。

指示学習の日本語の行は、文字の73%が日本語で、数学の問題の思考は英語で書かれている。これは `topics/nemotron-v2-ja-sft.md` の記録と合う。
