# 合格の線で読める差

v5 の 8k 版の点と問題数から、v6 と比べて読める差を 2026-11-01 に計算した。問題の選び方による揺れだけで、学習の乱数の揺れは入っていない。

v5 と v6 は別々に学習するので、独立な2つのモデルの差として計算した。対応のある値は、同じ事前学習を共有する 8k 版と 32k 版の指示学習の差から求めたもので、別の学習どうしではこれより大きくなるはずなので参考にとどめる。

平均では、英語12課題が .009、日本語8課題が .013。日本語の平均の揺れの多くは172問の M-IFEval-Ja から来る。MMLU の作者の形式と M-IFEval-Ja の公式の採点を入れると少し変わる。

21課題を2倍で判定すると、何も変わっていなくても、どれかが下がったと判定される確率は約4割ある（片側 2.3% として）。3倍なら約3%。

JMMLU が記号で答えられるようになるだけで日本語の平均は約 .031 上がり、それだけで .013 を超える。
