# 文書を読む順番

事前学習の文書をランダムに読まず、易しいものから難しいものへ並べる。データは捨てず、順番だけを変える。

[Zhang ら](../sources/curriculum-learning.md)は、0.5B、1更新約108万トークンのモデルで、同じ点に届くステップが18〜45%減り、順番に読んでからランダムに読むと最後の点も最大3.5%高いとした。結果は英語のデータと AdamW のもので、著者ら自身の比較しか見つけていない。

[別の研究](../sources/curriculum-dynamics.md)は、14M〜1B を 300B トークン学習して、学習の安定の差は大きいモデルほど小さいとしている。比べた順番の指標は Zhang らと違う。
