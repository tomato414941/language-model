# n-gram の計数を入力に足す（COUNT）

コーパスの n-gram を数えた表をメモリに置き、続きやすいトークンの出力の埋め込みを頻度で重み付けして入力に足す（[COUNT](../sources/count-ngram.md)）。学習するパラメータは増えない。

60M〜1B で、同じ計算の下流の点がほとんどの予算で上がり、検証損失の改善は計算を 46〜89% 増やしたのに相当する。課題の損失では 6〜56% に相当する。v6 の 520M、パラメータあたり16トークンはこの範囲に入る。

確かめていないこと。

- 計数は Dolma 3 全体で、v6 が読む 8.4B トークンの計数で同じだけ効くか。
- 日本語での効果。語の区切りがない言語では n-gram の意味が変わる可能性がある。
- 借りる機械のメモリに載る表の大きさでの効果。60M〜190M の表は 17.1GB、370M 以上は 797GB。

v6 には入れていない。次の世代を設計するときに、小さな実験の候補として検討する。見直し期限：2026-11-15。
