# 自分のモデルによるデータの書き直し

学習データの文章を、自分たちのモデルで別の形に書き直して足す。

[FinePhrase の論文](../sources/finephrase.md)では、小さな書き手でも元の Web だけより良かった。1.2B のモデルで、FineWeb-HQ だけが 11.82 のところ、書き手が [SmolLM2](../sources/smollm2.md) の 135M で 12.69、360M で 14.45、Gemma 3 の 270M で 13.80。ただし著者らは 270M を足りないと見ており、1B の 15.31 より低い。書き手は既存の公開モデルで、1億〜4億パラメータの自作モデルで書いた報告は見つけていない。日本語の報告も見つけていない。
