# M-IFEval-Ja

日本語の指示に従えるかを、規則で採点する評価（tokyotech-llm/M-IFEval-Ja）。公式の採点コード（lightblue-tech/M-IFEval、commit 10b874d）で採点すると、公開されている Qwen2.5-0.5B と gpt-4o-mini の結果を、strict と loose のどちらも 172/172 で再現できた。llm-jp-eval v2.1.5 にも入っている（mif_eval_ja）。

llm-jp-eval の既定の設定は、返答を最初の空行で切ってから採点する。公式の採点コードは返答全体を見る。2026-10-31 に、3億パラメータの自作モデルの返答を調べると、172件中124件が切られ、採点されたのは文字数の27%だった（文字数の中央値は628字から102字）。空行で段落を数える指示は、切られると満たせない。一方、使ってはいけない語の指示のように、短いほど有利なものもある。

llm-jp-eval v2.1.5 の strict の関数は、ループの中で return している。コードを読むかぎり、複数の指示がある問題（172問中44問）でも最初の指示しか見ない。実行して確かめてはいない。
