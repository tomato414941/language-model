# 語彙の大きさ

[語彙が大きいほど良いという研究](../sources/large-vocabulary.md)がある。日本語のほうが差が大きく、常識の課題の平均は 1T トークンで 5k の 49.4 から 100k の 57.1、500k の 58.6 に上がった。同じトークン数で読めるデータも増える。LLM-jp-4 は 196,608 を使っている。語彙を大きくすると、埋め込みと value embeddings の表が、その分大きくなる。

語彙32,768では、[1トークンで読める文字数](../experiments/tokens-per-character.md)は日本語が英語の半分ほどだった。

[言語ごとの部分語彙](../sources/modular-tokenizers.md)は、バッチごとに部分語彙を選び、その中だけでロジットを計算して学習する。語彙全体を使う計算は 24k の1言語と比べて 0.5B で1.58倍で、語彙の費用は小さなモデルほど大きい。語彙を増やす案と組み合わせられるが、日本語の結果は読んだ範囲にない。

[トークナイザの比較](../sources/tokenizer-choice-languages.md)は、学習データの割合が小さい言語ほど選び方が効くとした。v6 は日英同じバイト数でトークナイザを学習し、学習データも半々なので、この研究の「割合の小さい言語」には当たらない。
