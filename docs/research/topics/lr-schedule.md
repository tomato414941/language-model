# WSD の学習率の下げ方

WSD で、最後のどれだけの期間に、どこまで学習率を下げるか。

[IMU-1](../sources/imu-1.md)（arXiv 2602.02522、7000万パラメータ、1-sqrt）の比較では、学習損失は次のようになった。下げる期間は20%がよく、10%は下げないより悪かった。

| | 学習損失 |
|---|---|
| cosine | 3.125 |
| 下げない | 3.188 |
| 10%で下げる | 3.234 |
| 20%で下げる | 3.125 |
| 30%で下げる | 3.172 |

[Straight to Zero](../sources/straight-to-zero.md)（arXiv 2502.15938）は、最適な学習率のもとでは、0まで直線で下げるのが一番良いとしている。610M のモデルでは、0まで下げて 80 TPP 学習したほうが、10分の1までの下げ方で 200 TPP 学習するより損失が低かった。

nanochat は最後の65%で5%まで下げている。LLM-jp-4（arXiv 2610.19331）は 1-sqrt で0まで下げ、試した範囲では下げる期間が長いほど良くなり続けたとしている。30%で悪くなった IMU-1 とは食い違う。

[データと学習率の順番の研究](../sources/data-lr-schedules.md)は、質の高いデータに切り替えてから遅れて下げるほうが、そのデータの損失が低いとした。630M では切り替え後の期間の最後の40%で下げるのが最良で、期間全体で下げるより 0.014〜0.024 低い。v6 は減衰期のデータに切り替えると同時に下げる。事前学習のデータの損失と下流の点は読んでいない。
