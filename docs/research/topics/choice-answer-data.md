# 選択式の答え方を学ぶデータ

選択肢の記号だけで答える会話。文章や思考で答える会話では身につかない（[自分たちのモデルの結果](../experiments/choice-answers.md)）。2026-10-31 に取得して数えた。

| データ | 問題数 | ライセンス | 記号 |
|---|---|---|---|
| [KUCI](https://github.com/ku-nlp/KUCI) の学習用 | 83,127 | CC BY-SA 4.0 | 数字 |
| [JCommonsenseQA](https://github.com/yahoojapan/JGLUE) の学習用 | 8,939 | CC BY-SA 4.0 | 英字 |
| [JAQKET](https://sites.google.com/view/project-aio/dataset) の第1回の学習用 | 13,061 | CC BY-SA 4.0 | 英字 |

- KUCI と JCommonsenseQA は評価の課題そのもの。同じ形式で練習するので点が上がりやすく、実力の伸びと区別しにくい。学習に入らない JMMLU が、記号で答える力が他の問題に効くかの目安になる。
- JCommonsenseQA は、評価に使う分割の1,119問のうち17問が学習用にもある。該当する23行を除いて8,916問を使う。KUCI の学習用には、評価の問題と文脈と正解の両方が同じものはなかったが、文脈だけ同じものはある。
- JAQKET の候補は答えが先頭に並ぶので、最初の4つを問題ごとに決まった順に並べ替える。
- 語彙32,768の日本語の指示学習のデータに足すと、会話は約10万件増えるが、答えのトークンは約31万で、学習対象の0.3%ほどにしかならない。
