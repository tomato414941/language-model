# RTX 5090

[Puro-2B](../sources/puro-2b.md) は RTX 5090 で 2B を学習した。Blackwell は MXFP8 のブロックごとのスケールが使え、1.7B で FP8 の速さは1.36倍、検証損失の悪化は 0.0031〜0.0039。論文は公開のレンタルが少ないとして償却で費用を計算している。

2026-11-01 の Vast の掲載価格（1台、信頼度0.98以上、下り 500Mbps 以上、メモリ 32GB 以上、中国を除く、本番の条件より少し緩い）：

| GPU | 掲載数 | 最低 | 中央値 | GPU メモリ | dlperf |
|---|---|---|---|---|---|
| RTX 4090 | 49 | $0.360/時 | $0.48 | 24GB | 126 |
| RTX 5090 | 45 | $0.493/時 | $0.82 | 32GB | 200 |

最低価格の比は1.37倍、dlperf の比は1.6倍。dlperf は Vast の指標で、v6 の学習での速さは測っていない。32GB なら1回の窓を増やせる可能性がある。

2026-11-05 に v7 の形で測った（[v7 の速さ](../experiments/v7-throughput.md)）。v6 と同じ形（約3.9億）で、bf16 は毎秒 48,500 トークン、FP8（注意の入力は bf16）は 59,400、1回の計算で2窓を処理すると 64,100。約7.2億では bf16 が 28,900、FP8 が 36,000。1ドルあたりでは、v6 の設定（RTX 4090、bf16）の約1.3倍。文書ごとに区切った注意をコンパイルしても、NaN は出なかった。v6 の測定で NaN が出たのは、2回とも同じ1台の機械だった。

計算能力 12.0 の 5090 で使えないもの：

- 専門家の行列の FP8：PyTorch の `torch._scaled_grouped_mm` は計算能力 9.0 と 10.0 だけ。
- MXFP8 と FP4 の学習（[5090 の行列計算の記事](../sources/rtx-5090-matmul.md)、[TransformerEngine の issue](../sources/transformer-engine-sm120.md)）。
- FlashAttention-3（Hopper 専用）と FlashAttention-4（[SM120 で NaN の報告](../sources/fa4-sm120-nan.md)）。PyTorch に入っている FlashAttention-2 は動く。

2026-11-05 の Vast の値段（1台、通常の借り方）：5090 は $0.48〜0.53、RTX 4090 は $0.36〜0.41。中断されうる 5090 の入札は、多くが $0.43〜0.46 だった。
