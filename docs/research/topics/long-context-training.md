# 長い文脈の続きの学習

短い文脈の後に長い文脈で続けて学習する。v5 の 32k 版は約 0.5B トークンを読み、続く指示学習と合わせて $5.86 かかった（`results.md`）。

[スケーリング則の研究](../sources/long-context-scaling.md)は、1.22B を 32K で約 100B トークンまで読んでも長い文脈の点が上がり続けるとした。評価は RULER などの長い文脈の課題で、世代の判定に使う評価（`evaluation.md`）には入っていない。

v7 まで文脈は 8,192 で、この学習をしていない。長い文脈の評価を判定に入れる世代で読み直す。見直し期限：2026-12-15。
