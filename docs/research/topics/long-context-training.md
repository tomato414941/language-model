# 長い文脈の続きの学習

短い文脈の後に長い文脈で続けて学習する。v5 の 32k 版は約 0.5B トークンを読み、続く指示学習と合わせて $5.86 かかった（`results.md`）。

[スケーリング則の研究](../sources/long-context-scaling.md)は、1.22B を 32K で約 100B トークンまで読んでも長い文脈の点が上がり続けるとした。評価は RULER などの長い文脈の課題で、v6 の合格の線の課題には入っていない。

v6 は文脈 8,192 で、この学習をしない。長い文脈の評価を合格の線に入れる世代で読み直す。見直し期限：2026-11-15。
