# 事前学習の領域の混ぜ方の決め方

- [LinMix](../sources/linmix.md)：小さなモデルを、各領域を上限まで入れるか入れないかの組み合わせで学習し、線形回帰の係数で決める。1B と 4B で Dirichlet の方法より上。必要な小さなモデルの数は読んでいない。
- [LARE](../sources/lare.md)：読むデータの割合は変えず、損失の重みを実行中に決める。追加の実行が要らない。1.5B、240B トークンで5つのベンチマークの平均が +7.84。要旨だけを読んだ。
- [Puro-2B](../sources/puro-2b.md)：共通の重みから候補のデータで2000ステップ続けて学習し、15のベンチマークで比べる。

どれも日本語を含む比較ではない。

[Repetition Mismatch](../sources/repetition-mismatch.md) は、小さな実験で繰り返しの回数を揃えることを勧めている。文書を繰り返さない v6 の方針なら、この問題は小さい。
