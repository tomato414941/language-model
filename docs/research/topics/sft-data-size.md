# 指示学習のデータ量

事前学習の Chinchilla のような、パラメータあたりのトークン数の目安は、2026-11-01 に探した範囲では見つからなかった。3回検索して読んだ範囲で、探し尽くしてはいない。

分かっていること。

- 損失はデータ量のべき乗で下がり、減り方は緩やかになる（[データの混ぜ方の研究](../sources/sft-data-mixing.md)、[Rectified Scaling Law](../sources/rectified-scaling-law.md)）。
- 事前学習は、ファインチューニングのデータ量を実質的に何倍にもする（[Scaling Laws for Transfer](../sources/scaling-laws-transfer.md)）。
- 7B と 8B では、ランダムに増やすと50万件まで点が上がり続けた。増えたのは広さ（[広さと深さの研究](../sources/sft-coverage-depth.md)）。
- 領域の最適な重みはデータ量によって変わる（データの混ぜ方の研究）。小さな学習で係数を当てはめて計算できる。0.5B も比べている。
- 特定の力に向けたデータは、なければ点が大きく下がる。8B で IFEval が 72.8 から 53.6（[Tülu 3](../sources/tulu-3.md)）。

分かっていないこと。

- 5億パラメータのモデルに要る指示学習の量。上の結果の多くは 7B 以上で、指標も違う。
- 日本語での結果。

v6 は約52万会話、学習対象は約2億トークンを2エポック読む。Tülu 3 の 8B は約94万会話。
