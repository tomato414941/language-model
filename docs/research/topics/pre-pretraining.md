# 合成データで先に学習する

事前学習の前に、人工的な課題のデータを少し学習する。

- [2026-09 の研究](../sources/synthetic-pre-pretraining-scale.md)：500M〜7B で効果が残り、3B で少なくとも 21B トークン分を節約した。
- [2026-10 の研究](../sources/rethinking-pre-pretraining.md)：計算量を揃えると自然言語だけの学習を超えず、以前の効果は初期化に左右された。

結論が逆で、どちらも要旨しか読んでいない。v6 には入れていない。結論が揃う研究が出たら検討する。見直し期限：2026-11-15。
