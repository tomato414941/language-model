# 複数のトークンを先まで予測する学習（MTP）

各位置で、次のトークンだけでなく、その先のトークンも予測させる。

[nanochat の LOG](../sources/nanochat-log.md)（2026-01-12、d12）では、メモリが 34GB から 47GB に増え、ステップあたりは同じか少し悪く、時間で比べるとはっきり悪かった。

[Soft-MTP](../sources/soft-mtp.md) は勾配のうち雑音の多い成分を除く。標準の MTP との差は 167M と 332M で約0.1点、689M と 1.2B で約0.5点。MTP なしの基準を超えるのは 689M 以上で、v6 の 520M では費用に見合う根拠がない。689M 以上の世代では検討する。見直し期限：2026-11-15。

[ECHO](../sources/echo-mtp.md) は本体の最後の層で複数のトークンを予測し、下流の点が上がるとした。結果は 10B（活性 1B）を 600B トークン読んだもので、v6 の大きさとは桁が違う。v6 には入れていない。1B 以下の結果が出たら読み直す。見直し期限：2026-11-15。
