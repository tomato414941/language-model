# 指示学習の学習率

v6 は 0.00016（1更新 262,144 トークン）。事前学習のピーク 0.0032（1更新 1,048,576 トークン）を平方根の規則で同じ更新の大きさに直すと 0.0016 で、その10%にあたる。

| 出典 | 事前学習のピーク | 指示学習 | ピークとの比 | 条件 |
|---|---|---|---|---|
| [Muon と AdamW の切り替えの研究](../sources/optimizer-switch-sft.md) | 2e-3 | 8e-4 | 40% | 1.2B、1×、Muon → Muon。検証損失で選択 |
| 同上 | 2e-3 | 4e-4 | 20% | 1.2B、1×、AdamW → Muon |
| [LLM-jp-4](../sources/llm-jp-4.md) | | | 13% | 8B と 32B-A3B |

同じ研究で、他の人が公開したモデルの指示学習では最良が 1e-5〜5e-5 だった。1.2B の結果と1桁以上違う。トークンを多く読んだモデルほど小さいのかは確かめていない。

1.2B の指示学習の1更新のトークン数は本文で見つけていないので、40% は同じ更新の大きさでの比ではない可能性がある。40% を v6 に当てると 0.00064。

Muon で指示学習すると点は上がるが、事前学習のデータの損失はより上がるとも報告されている。v5 は指示学習で JNLI と JCommonsenseQA が下がった（[記録](../experiments/jcommonsenseqa-drop.md)）。学習率を上げれば良いとは言い切れないので、v6 では 0.00016 と 0.0006 を走らせて比べる。
