# ブロックを足す

学習済みのモデルに層を足して、続きを学習する。[LLaMA Pro](../sources/llama-pro.md) は、足した層を新しいデータだけで学習して、元の能力を保った。足す層の出力が0から始まれば、足した直後のモデルは元と同じ予測をする。

層を足しながら学習する研究もある。[G_stack](../sources/g-stack.md) は、7B で普通の学習の損失に 54.6% 少ないトークンで届いた。[CGLS](../sources/cgls.md) は易しいデータからのカリキュラムと組み合わせて上回ったが、検索の要約では、カリキュラムなしに層を足すだけでは計算をそろえると同じか悪い。

[2026-10 の自分たちの試し](../experiments/growth-probe.md)では、同じ GPU 時間で、層を足したモデルとそのまま続けたモデルに差がなかった。
