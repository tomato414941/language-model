# [NorMuon](../sources/normuon.md)

Muon で直交化した更新の2乗平均を、ニューロン（行か列）ごとに移動平均で持ち、その平方根で割る。そのあと、全体の大きさを直交化した直後のものに戻す（arXiv 2510.05491）。更新の大きさが Muon と同じなので、Muon の学習率の決め方がそのまま使える。nanochat の nanochat/optim.py に実装がある（beta2 0.9）。

[IMU-1](../sources/imu-1.md)（arXiv 2602.02522）の 7000万パラメータの比較では、学習損失が AdamW の 3.250 から NorMuon で 3.156（−2.88%）になった。

[小さなモデルの比較](../sources/muon-time-budget.md)（17.7M と 33.6M、参照実装）では、同じデータ量では Muon が良いが、時間で揃えると AdamW が 3〜7% 良く、Muon の呼び出しが学習時間の56〜70%を占めた。v6 の 520M のコンパイルした実装で同じかは測っていない。v6 の更新の時間の内訳を測るときに読み直す。見直し期限：2026-11-15。
