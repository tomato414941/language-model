# 1B 未満への強化学習（RLVR）

正解を自動で判定できる問題で、強化学習をする。数学とコードの報告は 1.5B 以上で、[1.5B〜7B の研究](../sources/grpo-small-models.md)では数学は伸び、多肢選択の知識の課題はあまり伸びなかった。1B 未満では、[Qwen3.5-0.8B に検索の道具を使わせた報告](../sources/rlvr-small-search.md)があり、完全一致だけの報酬は悪く、部分点のある報酬が要るとしている。v7 まで強化学習は入れていない。数学やコードを答えさせて測る評価を判定に入れる世代で、入れるかを決める。見直し期限：2026-12-15。
