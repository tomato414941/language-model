# ANVIL

Muon と NorMuon を組み直したオプティマイザ（modded-nanogpt の[記録 #92](studies/modded-nanogpt-anvil2.md)）。

- 速いものと遅いものの2つのモメンタムを混ぜて、Nesterov の先読みに使う。
- 直交化の多項式の係数を求め直す。
- 行ごとの大きさをそろえ、遅いほうのモメンタムで cautious weight decay を判断する。
- 最後の約300ステップの EMA を重みに混ぜる。

更新則だけを前の記録の Muon に戻すと、時間は 0.47 秒減り、損失は 4.9 ミリナット悪くなる。オプティマイザ全体を戻すと、時間はほぼ同じで 21.1 ミリナット悪くなるので、差の大半は最後の重みの作り方から来ている。
