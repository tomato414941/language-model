# HobbyLM: A Sparse Mixture-of-Experts Model Family on a Hobby Budget

arXiv 2610.34582（2026-10）。要旨、最適化、比較、500M の事前学習と評価、チャットのモデル、1B の結果と分析、限界の節を読んだ。

細かい MoE を数百〜数千ドルの GPU 代で学習した。HobbyLM-500M は 501M（活性 169M）で FineWeb を 40B トークン、8×H100 で約13時間、1更新 1,048,576 トークン。検証損失は 3.0281。Muon のピークは 0.04、weight decay は 0.1、減衰は最後の40%で0.1倍まで。

## 0-shot の評価

同じハーネスで揃えて測っている。

| モデル | パラメータ | トークン | 7タスクの平均 |
|---|---|---|---|
| SmolLM2-360M | 360M | 4T | 56.29 |
| Qwen3-0.6B | 600M | 36T | 54.78 |
| Pythia-410M | 410M | 300B | 45.34 |
| HobbyLM-500M | 501M/169M | 40B | 44.05 |
| OPT-350M | 350M | 180B | 43.61 |
| HobbyLM-130M | 140M/62M | 10B | 42.97 |
| MicroLlama-300M | 300M | 50B | 42.23 |
| GPT-2 | 124M | 不明 | 40.62 |

順位はパラメータ数よりトークン数に沿うとしている。HobbyLM-1B（1.04B、活性 305M、100B トークン）は 47.54。

指示学習は約150万会話の SmolTalk を 28k ステップ、続けて DPO。平均は 44.0 から 42.5 に下がり、BoolQ が最も下がった（51.0→44.4）。

## 比較（130M、3000 ステップ、1回ずつ）

基準の検証損失は 3.6688。QK-norm を外すと +0.803。z-loss を外すと +0.041、専門家を32から16に減らすと +0.048、top-8 にすると −0.025。0.01 程度の差はノイズの範囲としている。

## データの順番

出典ごとに順に読むローダーでは検証損失が 3.74 から 5.13 に上がった。出典を混ぜて読むと、同じデータとモデルで FineWeb 10B と同じ点（43.34 と 42.97）に半分のトークンで届いた。最初の断片の出典と、学習の3等分ごとの混ぜ方を出力して確かめることを勧めている。
