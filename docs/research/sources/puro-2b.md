# Puro-2B: Poor Lab's Qwen2-1.5B Trained on RTX 5090 within $5090

arXiv 2608.27370（2026-08）。要旨、GPU と FP8 と最適化と文書の順番の節、データの節の前半、費用の節の一部、事後学習の節を読んだ。

2B パラメータを RTX 5090 で最大 1.4T トークン学習した。良いモデルの費用は $6.9K で、Qwen2.5-1.5B に近い。一様に読むモデルは $4.4K とされる。費用は8台のノードを5年で償却して計算していて、RTX 5090 は公開のレンタルが少ないとしている。

## 費用を下げた要因

要因ごとに基準が違い、掛け算できないと断っている。

| 要因 | 効果 | 条件 |
|---|---|---|
| RTX 5090 | 価格あたりのピークの計算量が H200 の2.77倍（bf16） | 仕様と価格からの計算 |
| ブロックごとの FP8 | 速さ1.36倍、損失を入れて1.34倍。検証損失は 0.0031〜0.0039 上がる | 1.7B、Blackwell の MXFP8。活性は128個ずつ、重みは128×128のブロックごとにスケールを持つ |
| Hyperball の Muon | 同じ損失に要る計算が16.1%少ない（1.19倍） | パラメータあたり20トークンのモデルの列 |

## 文書の順番と平均

質のスコアがあるデータを低いものから高いものへ並べ、データの混ぜ方は保ったまま読む。最後は学習率を一定にして続け、6つの重みを平均する。

| 指示学習の種類 | 一様に読む | 順番と平均 |
|---|---|---|
| 数学（小） | GSM8K 66.89 | 68.66 |
| 数学（大） | GSM8K 74.10 | 76.12 |
| 広い指示 | 15タスクの平均 54.99 | 56.58（15のうち13で上） |

## データの選び方

0.6B の共通の重みから候補のデータで2000ステップ続けて学習し、15のベンチマークで比べる。スコアのある大きなデータは、25%刻みで切り出して別々に測る。
