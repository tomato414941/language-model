# Demystifying Synthetic Data in LLM Pre-training

arXiv 2510.01631（EMNLP 2025）。要旨を読んだ。

1,000 以上のモデル、10 万 GPU 時間以上で、合成データを規模則で比べた。

- 言い換えたデータだけでは、Web の文章より速く学べない。
- 言い換え1/3と Web 2/3 の組み合わせは、大きなデータ予算で同じ検証損失に5〜10倍速く届く。良い割合は、言い換えで約30%に収まる。
- 約8B より大きな書き手のモデルを使っても、事前学習のデータは良くならない。
- 教科書の形の合成データだけでは、小さな予算で多くの分野の損失が高く、モデル崩壊に似た傾向がある。言い換えには見られない。
