# When Does Muon Actually Win?

arXiv 2610.21555（2026-10）。要旨だけを読んだ。本文は取得できなかった。

17.7M と 33.6M の言語モデルを A100 1台で、Muon と AdamW で比べた。同じデータ量では Muon が検証損失の面積を 3.25〜22.44% 減らし、テストの損失は20組すべてで低い。時間で揃えると、言語モデルでは AdamW が 3.38〜6.96% 良い。Muon の呼び出しが学習時間の 56.1〜69.6% を占めた（AdamW は 6.1〜9.1%）。小さなモデルと参照実装の結果で、大きなモデルや最適化した実装の順位は示さないとしている。
