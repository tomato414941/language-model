# How Much Is an AI Token Worth? Scaling Laws for Wild AI-Generated Web Text

arXiv 2609.40295（2026-09）。要旨とはじめにを読んだ。

Web の文章のうち AI が書いたものの影響を、800のモデル（19.9M〜973M）で測った。

- FineWeb の質のフィルタを通った Web のトークンのうち、Pangram が AI と判定した割合は、2024-06 に約10%、2025-06 に16%、2026-06 に28%、2026-08 に31%。
- 人の文章のトークンが少ないモデルでは、AI の文章を足すと人の文章の損失が下がる（パラメータあたり約10トークン未満）。多いモデルでは、すぐに上がる。
- 2026-08 の割合で未処理の Web を読むと、パラメータあたり20トークンで、人の文章だけを読むより1.6倍の計算が要る。
- 人の文章が目的なら、AI の文章を除くこと、増やすより人の文章を繰り返すこと、検証損失を人と AI で分けて報告することを勧めている。

対象は多くのモデルが人の読者向けに書いた、ラベルのない文章で、合成データの研究とは条件が違うとしている。日本語の割合は読んだ範囲にない。
