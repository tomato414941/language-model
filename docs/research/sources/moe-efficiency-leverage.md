# Towards Greater Leverage: Scaling Laws for Efficient Mixture-of-Experts Language Models

Ling チーム（Ant Group）、arXiv 2507.17702。要旨と本文の前半（約3分の2）を読んだ。

28B までの 300 以上のモデルで、MoE が同じ性能の密なモデルに対して何倍の計算に相当するか（Efficiency Leverage）を調べた。

- 専門家が使われる割合が小さいほど効率が上がる。試した最小の 0.8% が、どの計算量でも最良だった。
- 効率は計算量とともに上がる。
- 専門家の細かさは12前後が最良で、計算量によらない。
- 共有の専門家の割合は、1e20 FLOPs 以下で 16.7%、それより上で 8.3%。共有の専門家は1つを勧める。
- 試した全ての大きさで、MoE は密なモデルより計算あたり効率が良かった。学習の初めは密なモデルの方が早く進み、MoE が後から追いつく。
- 0.85B を使う MoE（全体 17.5B）が、同じ 1T トークンで密な 6.1B に並び、計算は7分の1以下だった。
