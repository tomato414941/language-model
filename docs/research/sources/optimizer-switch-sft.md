# The Ephemeral Cost of Switching Optimizers Across LLM Training Stages

arXiv 2610.22650（2026-10）。本文の主な節、付録の設定、学習率の表を読んだ。図の中の数字は読めていない。

1.2B の Llama 3 形を、1×（24.16B トークン）と 8×（193.29B トークン）の Chinchilla で、AdamW と Muon の割合を変えて事前学習した。指示学習は Tülu 3 の混合を2エポック。

- 事前学習と指示学習で最適化手法を揃える利点は小さかった。点は、それぞれの段階の手法の効果でほぼ説明できた。
- 指示学習で Muon の割合を上げるほど、下流の点は上がった。
- 一方で、指示学習で Muon を増やすと、事前学習のデータの検証損失はより上がった（忘却）。事前学習が Muon だと、この忘却は減った。

| 事前学習 → 指示学習 | 6つのベンチマークの平均（1×） | （8×） |
|---|---|---|
| AdamW → AdamW | 15.8 | 22.0 |
| AdamW → Muon | 17.2 | 21.9 |
| Muon → AdamW | 17.0 | 24.7 |
| Muon → Muon | 18.8 | 27.6 |

## 学習率

指示学習の学習率は、検証損失が最も低いものを選んでいる。

- 1× の 1.2B で、Muon で事前学習したモデルの最良は 8e-4、AdamW で事前学習したモデルの最良は 4e-4（どちらも指示学習が Muon のとき）。
- 事前学習の Muon のピークは 2e-3、1更新は 1,048,576 トークン。
- 指示学習の1更新のトークン数は、1.2B については本文で見つけていない（4096 トークンに詰めるとだけ書いてある）。
- 他の人が公開したモデルは1更新 524,288 トークンで、最良は Qwen2.5-7B が 2e-5、Qwen3-4B と 8B が 2e-5、14B が 1e-5、Llama 2 7B が 5e-5。

1.2B の指示学習の設定は、3% のウォームアップのあと0まで直線で下げる。Muon のモメンタムは 0.98、weight decay は 0.1。補助の AdamW の学習率は 5e-5。
