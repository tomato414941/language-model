# Arkios

arXiv 2608.30092（2026-08）。要旨と評価の節を読んだ。

英語とネパール語の 1.04B を 150B トークンで学習した。8×H100 で約79時間、約$2,500。

- Belebele（900問、4択、偶然は 0.250）を記号の形式で問うと、ネパール語 0.240、英語 0.236 でどちらも偶然の水準。答えの文の確率を比べる形では 0.306 と 0.387。著者らは、読解の力ではなく記号の形式に従う力の不足だとしている。
- 同じ問いを2つの言語で問うと、形式の失敗と言語の力の差を区別できるとして勧めている。
- ARC では同じ大きさの公開モデルを超えたが、学習データの教育的な文章と問題の形が合ったためでもあるとしている。
