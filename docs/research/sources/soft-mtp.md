# Multi-Token Prediction Done Right

arXiv 2610.38331（2026-10）。要旨、はじめに、下流の評価、費用の節を読んだ。

MTP の勾配を KL の成分と雑音の多い残りに分け、KL の成分だけを流す（Soft-MTP）。標準の MTP と同じ計算量とメモリで、追加のパラメータもない。比べたのは MTP の頭3つの Llama 形、167M〜1.2B。

- 標準の MTP に対する平均の点の差は、167M と 332M で約0.1、689M と 1.2B で約0.5。
- MTP なしの基準を超えるのは 689M 以上。標準の MTP は小さいモデルで選択問題の点を上げない。
- 1.2B の数学とコードの指示学習の後は Soft-MTP が高い（HumanEval pass@64 が MTP なし 39.02、MTP 40.85、Soft-MTP 43.90、GSM8K が 47.69、48.60、49.66）。
