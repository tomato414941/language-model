# "High-Quality" Data for Early-Stage Instruction Tuning

arXiv 2610.33969（2026-10）。要旨、はじめに、方法、結果の一部を読んだ。

指示データの質の指標を4つ（長さ、返答の割合、整合、意味の密度）比べた。例を指標で3つに分け、トークン数を揃えて別々に学習する。Qwen3.5-9B-Base と Llama-3.1-8B を LoRA で3エポック、データは Natural Instructions と FLAN。

- 最も安定して役に立つ例を見分けたのは、返答の割合（返答のトークン数÷問いのトークン数）だった。
- 他の指標の効果の一部は、返答の割合との重なりで説明できる。
- 検証の perplexity では差が出たが、LLM の判定の点は信頼区間が大きく重なる。学習の初期だけを見ている。
