# Terminal Shrinkage Averaging

arXiv 2609.25482（2026-09）。要旨、導入、結果の一部、結論を読んだ。

最後の重みと最後の数個の重みの平均を、係数 α で混ぜて返す。

- nanochat の d12 で、最後の8個（32ステップおき、学習の約7.5%）の平均を混ぜた。最良は α=0.40 で BPB −0.00079、α=0.55 で −0.00071。平均だけを使う α=1（LAWA）は +0.00073 で、最後の重みより悪い。
- 学習率の下限を 5% から 10%、15% に上げると、最後の重みは悪くなり、混ぜた重みは良くなる。AdamW だけでも向きは同じ。
- d22 でも、同じ計算で検証の BPB が3回とも良くなった。
