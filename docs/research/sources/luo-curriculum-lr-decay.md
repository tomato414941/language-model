# How Learning Rate Decay Wastes Your Best Data in Curriculum-Based LLM Pretraining

Luo ら、arXiv 2511.18903。要旨と本文（HTML 版 v3）を読んだ。arXiv のページに会議の採択の記載はない。

Qwen2.5-1.5B の形を DCLM-Baseline の 30B トークンで学習し、DCLM の fastText の点の低い順に読ませた。最大の学習率 3e-3、既定の最終の学習率 1e-5（最大の約1/300）。

- 最後まで大きく下げると、質の順に読む効果がなくなった（一様に読む場合との平均の差 −0.22）。
- 最終の学習率を最大の約1/3にとどめるか、学習率を一定にして最後の6つの重みを平均すると、効果が戻った（平均 +0.39、中核の課題 +0.74）。両方を組み合わせた形が最良で、下げ幅を小さくするだけでもほぼ最良に近い。
- 平均の取り方は単純平均と指数移動平均がほぼ同じ（+0.38 と +0.39）。
- 一様に読むデータに指数移動平均を使っても、一様の WSD を下回った。
