# ATLAS

Longpre ら、ATLAS: Adaptive Transfer Scaling Laws for Multilingual Pretraining, Finetuning, and Decoding the Curse of Multilinguality（arXiv 2510.22037）。導入、節2〜5、付録 B.5〜B.7、表 C.1 の一部を読んだ。図2の値は、図の SVG に入っている文字から取り出した。図 C.1 と C.2 は読んでいない。

10M〜8B の774回の学習。データは MADLAD-400（Common Crawl 由来）、語彙 64k の SentencePiece。指標は検証損失。

## 言語の数

1言語あたりの損失を L∞ + A·K^φ/N^α + B·K^ψ/D^β で当てはめた。K は言語の数、N はパラメータ数、D はその言語のトークン数で、言語は均等に読む。全言語で φ = 0.11、ψ = −0.04、R² は 0.87 以上。

- 言語を r 倍にして損失を保つのに要る計算は、最小で r^0.97 倍。
- 言語を4倍にするときの例は、全トークン2.74倍、パラメータ1.4倍で、1言語あたりのトークンは32%減る。
- 損失には言語の数が N や D より強く効く。N のほうが D より効く。

## 言語の組

半々で読む2言語のモデルが、単独のモデルが 42B トークンで届く損失に届くまでの全トークンからスコアを計算する。0 は全トークンが2倍で、その言語のトークンが単独と同じ。負は干渉。図2は 2B で、10言語の総当たりは実測。日本語と英語を含む。

| 読む言語 → 測る言語 | スコア | 測る言語に要るトークン（単独との比、式からの計算） |
|---|---|---|
| 英語 → 日本語 | −0.6 | 1.3倍 |
| 日本語 → 英語 | −0.1 | 1.05倍 |
| 中国語 → 日本語 | −0.1 | 1.05倍 |
| 日本語 → 中国語 | −0.6 | 1.3倍 |
| 英語 → 中国語 | −1.0 | 1.5倍 |
| 中国語 → 英語 | −0.1 | 1.05倍 |

スコアは小数1桁まで。図の30言語で、日本語を測ると他の29言語すべてが負で平均 −0.85、英語を測ると平均 +0.03。文字や語族を共有する組は正になりやすい。
