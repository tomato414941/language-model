# Training Foundation Models with a Single Algorithm

arXiv 2610.40564（2026-10）。要旨と節5の一部を読み、2026-11-05 に本文（HTML 版）の前半を読み足した。

事前学習、中間の学習、指示学習、強化学習を、データの割合と順番の問題として1つの学習にまとめる。124M と 0.76B で比べた。大きな計算と最小の計算では段階を分けない形の正解率が高く、中間の計算では段階を分ける形が良い。事前学習と中間の学習を混ぜても、事前学習だけのモデルと同じくらい元の能力を保った。

本文で読み足したこと：

- 強化学習を、モデル自身の正解の答えへの最尤推定として書く（MaxRL）。1つの問題に N 個の答えを出させ、正解の答えに「1 / 正解率」の重みを付け、不正解は使わない。解けた問題は難しさによらず同じ重みで数えられ、一度も解けなかった問題は入らない。
- 強化学習に中間の学習のデータを 0.5〜5% 混ぜると、取り分けた中間の学習のデータでの損失が元のモデルより下がり、割合が大きいほど下がった。段階を分けた場合は上がった。数学の正答率はほぼ同じで、割合が大きいほどわずかに下がった。
- そのあとコードの強化学習を 4,000 更新すると、混ぜた形はすべて、HumanEval+ と MBPP+ で段階を分けた形より最終の正答率が高かった。5% が4つの指標すべてで最良。
- 124M は 20B トークンの事前学習と 510M トークンの中間の学習（推論の過程 796,175 本）、0.76B は 240M トークンの中間の学習と Math12K の強化学習。著者は、規模が小さいこと、1度に1つの課題しか学ばせていないことを限界に挙げている。
