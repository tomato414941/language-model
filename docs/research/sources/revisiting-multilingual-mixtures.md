# Revisiting Multilingual Data Mixtures in Language Model Pretraining

Foroutan ら（arXiv 2510.25947）。導入、節3の前半、各節のまとめ、節8を読んだ。

1.1B と 3B を 100B〜225B トークン学習した。30言語の mC4 と、最大400言語の FineWeb-2。日本語だけの数字は読んでいない。

- 全トークンを 100B に固定して英語を50%以上に増やすと、他の言語の損失は悪くなるが、下流の点は下がらない。英語の点は上がる。
- 他の言語を 90B に固定して英語を足しても、他の言語に悪影響はほとんどない。逆も同じで、十分なトークンがあれば、混ぜること自体は点を下げない。
- 言語を読む順番の工夫（最初に英語だけ、など）は、よく混ぜたものより良くならなかった。
- 言語の数を増やすことによる悪化は、言語の数そのものより、モデルの容量と、質の低いデータの影響が大きいとしている。

著者らの勧めは、割合の調整より、データの少ない言語のデータを増やしてきれいにすること。
