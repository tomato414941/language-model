# SonicMoE

Guo ら、SonicMoE（arXiv 2512.14080）と、Tri Dao の解説（tridao.me/blog/2026/sonicmoe-blackwell）。逆伝播で保存するものの節と解説を読んだ。

細かい MoE では、専門家に配ったトークンのコピーと専門家の出力が、使う専門家の数に比例して大きくなる。SonicMoE は逆伝播のために入力 X と最初の積（活性化の前）だけを保存し、配ったコピーと専門家の出力は保存しない。コピーは逆伝播でもう一度集め、点数の勾配は出力でなく中間の単位から計算する。活性化のメモリは45%減った。カーネルは Hopper と Blackwell のデータセンター向けで、RTX 5090（sm120）は対応予定とされている。
