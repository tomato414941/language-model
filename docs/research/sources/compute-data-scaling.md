# Bridging Compute- and Data-Optimal Pretraining

arXiv 2607.25271（2026-07）。要旨、導入、節5を読んだ。

14M〜600M を Dolma-3 で学習し、繰り返しや書き直しで作ったトークンが新しいトークンのどれだけに当たるかを当てはめた。

- その価値は、モデルの大きさ、パラメータあたりのトークン数、派生の量で変わり、増やすと飽和する。
- 計算、データ、モデルのどれが律速かで3つの領域に分かれる。
- 約 600M 以下で 1× Chinchilla 未満では、繰り返しより書き直しが良い。
- 大きなモデルへの外挿では、書き直しは 7B 以上かつ 4× Chinchilla 以上で効かなくなり、4エポックを勧められるのは 3B 前後で 1× Chinchilla ほどの場合だけ。
