# How to Use Parallel Data for Multilingual Pretraining

arXiv 2610.28838（2026-10）。要旨、導入、結論、結果の一部を読んだ。

文書とその機械翻訳を同じ窓に並べて読む学習を、1.3B、合計 120B トークンで比べた。英語とフランス語、英語とスワヒリ語。

- 対訳だけで読むと、一般の点は安定して上がらない。
- 対訳を読んでから普通に 20B 読むと、普通に読むだけより一般の点が上がる。HellaSwag は 1.83〜3.67 ポイント上がった。
- 翻訳の BLEU は英仏で 19.25 → 34.03、英スワヒリで 9.07 → 13.18。
