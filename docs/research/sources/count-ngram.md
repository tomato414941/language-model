# COUNT

arXiv 2610.20456（2026-10）。要旨、導入、節3.2、節4、節5.2、節6を読んだ。図の中の数字は読めていない。実装と計数は公開されている。

コーパスの n-gram を数えた表をメモリに置き、履歴に続きやすいトークンの出力の埋め込みを、頻度で重み付けして入力に足す。学習するパラメータは増えない。

- 60M〜1B、パラメータあたり10〜40トークンで比べた。検証損失の改善は計算を 46〜89% 増やしたのに相当し、課題の損失の改善は 6〜56% 増やしたのに相当する。41の選択式の課題の点は、同じ計算でほとんどの予算で上がった。
- 計数は Dolma 3 全体の6-gram まで。表は 370M〜1B が 797GB、60M〜190M が 17.1GB。
- 1B の学習の速さは普通の形の 93.1〜97.8%。
- 1B で学習した重みは、推論の時に1桁以上小さい表に替えても、普通の形より良い。
- GPU のメモリが限られる場合、学習する n-gram の表にメモリを分けるより、本体に使うほうが良い。
