# Beyond Random Sampling

Zhang ら（arXiv 2506.11300、EACL 2026）。事前学習の文書を、易しいものから難しいものへ並べて読む研究。要旨、設定、結果の本文、結論を読んだ。図の数字は読んでいない。

主な比較は 0.5B の Llama 3.2 風のモデル（16層、幅1536）で、AdamW、学習率 2e-4、1更新 1,081,344 トークン。データは英語（CulturaX の一部）。全体で200以上のモデルを最大 100B トークンまで学習した。難しさの指標は、圧縮率、文書のトークン数、MTLD、Fertility、Flesch Reading Ease、Perplexity の6つ。

- 順番を保って読むと、基準の最高の点に届くステップが減った。圧縮率で39.5%減、MTLD で31.7%減。Fertility は最高の99.5%まで45.3%減で届いた。
- 文書のトークン数で並べると、3B〜8B トークンの範囲でどのペースも基準を上回り、二次のペースで29.8%減、最後の点は1.1%高かった。
- 順番に読んだあとで、ランダムな 10B トークンを読み続けると、基準より3.5%と2.6%高かった（MTLD、最良と最後のチェックポイントから）。著者らは、この形が最も扱いやすいとしている。
- 順番に読んだ範囲のデータを混ぜ直して学習すると、ランダムよりは良いが、順番どおりより劣った。
- 1B（20B トークン）と 3B（40B トークン）でも効いたとしている。

著者らは限界として、デコーダだけのモデルで、英語のデータだけの結果であることを挙げている。
