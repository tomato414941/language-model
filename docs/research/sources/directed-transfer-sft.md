# A helps B while B hurts A

arXiv 2609.39702（2026-09）。要旨と結論を読んだ。

1つの専門のコーパスから作った指示学習の課題の種類を、どう組み合わせるかを調べた。Qwen3 と Mistral の 0.6B〜32B で数百回学習した。

- 種類を足せば良いとも、似たものを選べば良いとも限らない。A が B を助け、B が A を害することがある。干渉する1種類が、他の種類の効果の大半を打ち消した例がある。
- 各種類が各目標を助けるか害するかの表を作ると、未知の組み合わせの点を、組み合わせを見ない基準の半分未満の誤差で予想できた。
- ある大きさで選んだ組み合わせは、他の大きさでも全部入りに勝った。小さなモデルでは24回の学習で表を作っている。
- 推論の課題で、全部入りより最大14ポイント上がった。

題材は神経科学などの専門のコーパスで、一般のベンチマークの結果ではない。
