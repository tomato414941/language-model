# To Each Language Its Tokenizer

arXiv 2609.15528（2026-09）。要旨、結論、効率の節、実験の設定を読んだ。点の表の数字は読んでいない。日本語の結果は読んだ範囲にない。

21言語を1つの語彙で持ちつつ、言語ごとの部分語彙を取り出せるトークナイザを作る。学習ではバッチごとに部分語彙を選び、その語彙の中だけでロジットを計算する。

- 部分語彙の圧縮は、その言語だけのトークナイザと同じくらい。
- 語彙全体を使う計算は、24k の1言語の語彙と比べて 0.5B で1.58倍、30B で1.07倍。語彙の費用は小さなモデルほど大きい。
- 256k の語彙を 24k の部分語彙にすると、パラメータが 1B で47%、2.5B で35%、30B で10%減る（埋め込みを分けた場合。共有なら31%、21%、5%）。
- 学習の比較は埋め込みを除いて 2.5B。点は共有の語彙と同等としている。
