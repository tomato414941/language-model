# Monolingual or Multilingual Instruction Tuning

Chen ら、Monolingual or Multilingual Instruction Tuning: Which Makes a Better Alpaca（arXiv 2309.08958）。節3の一部と結論を読んだ。

7B と 13B を中心に、Alpaca とその機械翻訳で指示学習を比べた。計算をそろえると、言語ごとに分けて学習するより、まとめて学習するほうが良いか同等だった。6言語、5モデルの30例のうち、言語ごとの学習が上回ったのは2例。

評価は LLM による判定で、各言語50問。
