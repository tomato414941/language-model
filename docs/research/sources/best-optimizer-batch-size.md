# The Best Optimizer Depends on Batch Size

arXiv 2610.08975（2026-10）。要旨、導入、節3の規則の比較を読んだ。付録は読んでいない。読んだ範囲に NorMuon はない。

modded-nanogpt の最適化の部門の設定（FineWeb、1.7B トークン）で、1更新 128K〜2M トークンを比べた。

- 手法ごとに各バッチで調整すると、順位が入れ替わる。SOAP は 128K〜1M で最良、2M で3位。Muon は 512K で Shampoo に勝ち、2M で負ける。
- 128K で調整した Muon と AdamW の設定を大きなバッチへ移す規則を216通り比べた。256K と 512K では両方の学習率を平方根で上げるのが最良で、1M と 2M では学習率を据え置き、行列の weight decay をバッチに比例して上げるのが最良だった。全体で選ばれたのも据え置きの規則。
- 理論から導いた2つの規則は、1M 以上では何も変えない場合に負けた。
- モメンタムは変えないほうが良い。
- CIFAR-5M では別の規則が最良で、規則は設定に依存する。
