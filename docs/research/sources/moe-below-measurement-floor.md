# Below the Measurement Floor: A Pre-Registered Dense-vs-MoE Null at Sub-100M Active Parameters

ノート PC で、使う大きさ 3470 万の密なモデルと MoE（全体 6300 万、8つから2つ）を、1020 万トークンずつ学習した。MMLU、HellaSwag、WinoGrande はどれも当てずっぽうの水準で、構造の差を測れなかった。報告は、各専門家が密なモデルの4分の1のトークンしか見ないことを原因の候補に挙げている。
