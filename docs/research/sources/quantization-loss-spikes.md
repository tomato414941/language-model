# The Role of Quantization in Loss Spikes

arXiv 2610.38277（2026-10）。要旨とはじめに、実験の条件を読んだ。

学習の後半に急に損失が発散して戻らない現象を調べた。出力の頭のロジットが大きくなり、丸めの誤差が増えて起きるとしている。

- 精度を下げるほど早く起きる。bf16 の重みが最も早く、bf16 の計算が次で、fp32 では起きない。
- 頭の最適化を AdamW から モメンタムつき SGD に替えると防げる。
- 再現の条件は 404M を 96B トークン、1更新 131,072 トークン、weight decay なし。更新が小さいほど早く、weight decay があると遅れるとしている。
