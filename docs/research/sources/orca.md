# ORCA: The Annealed Spectral Conditioning Optimizer for Faster, Better LLM Training

arXiv 2610.06116（2026-10）。要旨、はじめに、手法と実験の節の一部を読んだ。

学習の初めの25%だけ、重み行列にソフトな直交化の罰則 `¼‖WWᵀ − I‖²` をかけ、その後は普通の Muon に戻す。罰則をかけている間は検証損失が高く、外したあとに追い越す。

- 1回の更新の行列積は、罰則の間だけ 24 回から 26 回に増える（8.3%）。8B の MoE では学習の1ステップの約0.8%、メモリはほぼ同じ。

| モデル | データ | Muon との損失の差 |
|---|---|---|
| LLaMA 130M | 50k ステップ | −0.0354（Muon 2.8460、ORCA 2.8106、Adam 2.8824） |
| LLaMA 350M | 100B トークン | −0.0194 |
| LLaMA 1.3B | 100B トークン | −0.0244 |
| 細かい MoE 0.8B〜8B | 最大 100B トークン | −0.020〜−0.025 |

- 1.3B では5つの下流のタスクすべてで Muon より高かった。
- 同じ損失に届くまでのトークンが40%少ない例がある。1.3B で、60k ステップで止めるように減衰を早めた続きの学習で、調整はしていない。
- Adam と SOAP に同じ罰則をかけても、130M で約 0.04 下がった。

比べている学習はパラメータあたり数十〜数百トークンで、1× 程度の短い学習の結果は読んだ範囲にない。NorMuon とも比べていない。
