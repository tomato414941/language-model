# Scaling Laws for Multilingual Language Models

He ら（arXiv 2410.12883、Findings of ACL 2025）。要旨、節4.2 の前半と表3、結論を読んだ。

85M〜1.2B、23言語を5つの語族に分けて100以上のモデルを学習し、語族ごとの損失をモデルの大きさ、データ量、読む割合のべき乗で表した。語族どうしの影響は独立に扱えるとしている。小さなモデルで求めた最適な割合が、1.2B でも効いた。

85M、50B トークンでの損失の合計（重みなし）。

| 割合の決め方 | 合計 |
|---|---|
| 均等 | 10.974 |
| トークン数に比例 | 11.025 |
| 平方根 | 11.012 |
| 式で求めた最適 | 10.969 |

合計では均等と最適の差はごく小さい。語族ごとの単独の損失で割った合計では、データの少ない語族に割合が増える。指標は損失で、5つの語族に日本語は入っていない。
