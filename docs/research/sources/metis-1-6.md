# Metis-1.6

arXiv 2610.37903（2026-10）。要旨、節4.2の始め、節6を読んだ。

1人で作った 2.94B と 10.23B（1パスの活性は 0.46B と 1.18B）。事前学習 804.76B トークン、指示学習 200B。40のベンチマークの平均は 10.23B で 52.93、17モデル中7位。

- 設定した最適化手法が動いていなかった。設定の名前が読まれておらず、名前の一致の誤りで注意の行列が事前学習の間ずっと AdamW で学習された。途中の監査で見つけた。
- 指示学習は2段階。長い推論だけの段階で IFEval 32.76%、全分野の段階の後で 71.07%。
- 指示学習の失敗として5つ挙げている。思考を削除して作った直接の答えの例は、見えない途中の作業を前提にしていて、直接の形の IFEval が10.92点低かった。教師の確かめ直しの癖を学んだ。古い教師の行が74.2%混ざっていた。
