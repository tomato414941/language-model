# Data Mixing Optimization for Supervised Fine-Tuning

arXiv 2508.11953。SFT のデータの混ぜ方を、検証損失を最小にする最適化の問題として解いた。本文の主な節と表を読んだ。付録は読んでいない。

- 検証損失をデータ量のべき乗の式で表し、領域ごとにデータ量を変えた小さな学習で5つの係数を当てはめて、最適な重みを計算する。
- Qwen2.5 の 0.5B と 1.5B、Llama の 3B と 8B で、5M、20M、200M トークンの予算を比べた。計算した重みの perplexity は、21通りの格子探索の最良より平均 0.66% 高いだけだった。
- 最適な重みはデータ量によって変わる。データ量が増えると重みの変化は緩やかになる。
- 3B で、一般の指示のデータを増やすと、数学とコードの損失も下がった。データを増やす効率は一般の指示が最も高く（β 0.051）、数学が最も低かった。ここの「指示」は一般の指示のことで、検証できる制約のことではない。
- 小さなモデルほど、一般の指示の損失が他の領域より高かった。
- Tülu 3 のデータの重みを変えても効果を調べている。下流の点の表は 8B の行の一部しか読んでいない。
