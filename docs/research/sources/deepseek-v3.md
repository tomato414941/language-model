# DeepSeek-V3

DeepSeek-V3 Technical Report（arXiv 2412.19437）。評価の節と結果の一部、負荷の均し方の節と比較を読んだ。

MoE の点は sigmoid で、選ぶ前に専門家ごとの偏り（速さ γ = 0.001）を足して負荷を均し、系列ごとの補助の損失（α = 1e-4）を弱く足す。均し方の比較では、検証損失が 1B で系列ごとの補助の損失 2.258、偏り 2.253、更新全体の補助の損失 2.253、3B で 2.085、2.080、2.080 だった。

事前学習のモデル（5-shot など）と chat のモデルを別々に評価している。chat のモデルは、MMLU、DROP、GPQA、SimpleQA で simple-evals の問いを使い、他社の非公開のモデルはそれぞれの API で評価した。自分たちのモデルに印をどう付けたかは、読んだ範囲には書かれていない。MMLU は chat のモデルで 88.5 と報告している。
