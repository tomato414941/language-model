# Demons in the Detail: On Implementing Load Balancing Loss for Training Specialized Mixture-of-Expert Models

arXiv 2501.11873。要旨、方法（Algorithm 1）、主な結果の表を読んだ。

負荷を均す損失は、ふつう少数の系列しか持たない小さな単位ごとに計算され、系列の中で専門家を均等に使わせてしまう。更新全体（グローバルバッチ）で計算すると、専門家が分野ごとに分かれ、事前学習の perplexity と下流の課題が良くなった。42.8B・400B トークンまで。

- 勾配を溜める更新では、各ステップで専門家ごとの選ばれた数をバッファに足し、それまでの合計から割合を出す。バッファは更新のあとで0に戻す。
- 損失の重みは先行研究に従う（表の基準は 0.008）。
- 全体 3.4B・能動 0.6B（専門家64から4つ）、120B トークンで、小さな単位で均すと平均 perplexity 8.167・MMLU 41.63、更新全体で均すと 8.038・43.48。
- 途中で更新全体に切り替えるより、初めから更新全体で均すほうが良かった（perplexity 7.383、10k ステップで切り替え 7.283、初めから 7.199）。
