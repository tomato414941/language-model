# Auxiliary-Loss-Free Load Balancing Strategy for Mixture-of-Experts

arXiv 2408.15664。要旨と、方法と偏りの更新の比較の節を読んだ。

専門家を選ぶ前の点に専門家ごとの偏りを足し、最近の使われ方に応じて動かして、負荷を均す。補助の損失による余計な勾配がない。3B・200B トークンまでで、補助の損失より性能も均し方も良かった。

既定の点は sigmoid。softmax で使うときは、偏りを使われ方の差の符号でなく差の大きさで動かした（速さ 1e-3）。速さ 1e-4 では学習の初めに均すのが遅く、1e-2 では使われ方が揺れた。
