# Gamayun

Gamayun's Path to Multilingual Mastery: Cost-Efficient Training of a 1.5B-Parameter LLM（arXiv 2512.21580、2025-12）。節3.1〜3.3 と結論を読んだ。付録の数字は読んでいない。

1.5B を 2T トークン学習し、さらに質の高いデータで 400B 読んだ。12言語で、ロシア語を重視している。

- 英語を37%から始めて後で約70%に増やした学習は、最初から70%以上の学習より多言語の点が高く、英語の点でも追いついた。
- 同じ英語のトークンでも、他の言語を足すと perplexity と LAMBADA が悪くなった（750M、Wikipedia）。
- 温度付きの割合と UniMax は、データの少ない言語を上げ、英語とロシア語を下げたので、トークン数に比例した割合を残した。
- 質の低いデータは、その言語の点を上げないだけでなく、質の高いデータの効果も下げる。同じ英語のデータで、ロシア語を増やすとロシア語は伸び続けたが、中国語は一定量を超えると伸びず、英語の損失の悪化も大きかった。

読む量は 1パラメータ1000トークン以上で、著者らは 10倍の計算で学習したモデルには難しい課題で及ばないとしている。
