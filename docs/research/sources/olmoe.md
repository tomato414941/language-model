# OLMoE

Muennighoff ら、OLMoE: Open Mixture-of-Experts Language Models（arXiv 2409.02060）。要旨と結論、設計の比較の節を読んだ。

7B のうち入力ごとに 1B だけを使う MoE を 5T トークンで学習し、同じ規模の能動パラメータのモデルより高い点を報告している。学習データ、コード、記録を公開している。

- 均しの損失（重み 0.01）と router の z-loss（0.001）を使う。均しの損失をなくすと、最初の層で全トークンが少数の専門家に集まった。
- 専門家を細かくするほど良くなったが、伸びは小さくなっていった。
- 同じ能動の大きさの密なモデルと同じ質に、3分の1のトークンで達した。ただし1秒あたりのトークンが37%少なく、時間では約2倍の得にとどまった。
