# llm-jp-eval の対応データセット

llm-jp-eval v2.1.5 の `DATASET.md` と `eval_configs/all_datasets.yaml` を読んだ。各課題の中身と点は見ていない。

課題ごとに出典、ライセンス、基本の例の数と答えの形式が書かれている。JBLiMP は0例で記号、JCoLA は4例で記号、MAWPS は4例で LaTeX の答え、JSTS、JSICK、JaNLI、Jamp、NIILC、JEMHopQA は4例でタグ付きの答え、JSeM は0例でタグ付きの答え、JCommonsenseMorality と JamC-QA は4例で記号。英語の OpenBookQA と WinoGrande_xl も入っている。
