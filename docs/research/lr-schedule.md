# WSD の学習率の下げ方

WSD で、最後のどれだけの期間に、どこまで学習率を下げるか。

IMU-1（arXiv 2602.02522、7000万パラメータ、1-sqrt）の比較では、学習損失は次のようになった。下げる期間は20%がよく、10%は下げないより悪かった。

| | 学習損失 |
|---|---|
| cosine | 3.125 |
| 下げない | 3.188 |
| 10%で下げる | 3.234 |
| 20%で下げる | 3.125 |
| 30%で下げる | 3.172 |

Straight to Zero（arXiv 2502.15938）は、最適な学習率のもとでは、0まで直線で下げるのが一番良いとしている。610M のモデルでは、0まで下げて 80 TPP 学習したほうが、10分の1までの下げ方で 200 TPP 学習するより損失が低かった。

nanochat は最後の65%で5%まで下げている。LLM-jp-4（arXiv 2610.19331）は 1-sqrt で0まで下げ、試した範囲では下げる期間が長いほど良くなり続けたとしている。30%で悪くなった IMU-1 とは食い違う。
