# BPE の前の区切り（pretokenization）

BPE を学習する前に、正規表現で文章を単語や数字のかたまりに区切っておく。GPT-2、cl100k、o200k、DeepSeek-V3 などが、それぞれの正規表現を使っている。データから学習したものではなく、人が決めたもの。

Cartesia の記事（From Tokens to Bytes II、2026-10-28）では、区切らずに学習した BPE は6.03倍に圧縮し、区切った BPE（4.57倍）より約32%多く圧縮したが、同じ損失に届く計算の効率は、区切った BPE のほうが1.5倍良かった。圧縮が良いことは、効率が良いことにならない。区切らない BPE では、問題文の終わりでトークンの切れ方がずれる問題が大きく、その補正をしないと OLMES の結果が意味をなさなかった。
