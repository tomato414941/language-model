# データ

## 決まり

- データセットの中身を細かくフィルタしない。除くのは、長さの範囲を外れる文書、同じ行を繰り返す文書、重複、評価の問題と、出典が持つ質の列の条件に合わない文書だけにする。
- v7 までは文書を繰り返して読んでいない。これは決まりではなく、ここまでの作り方。繰り返すかは、読む量を増やす世代で判断する（`candidates.md`）。見直し期限：2026-12-15。
- 非商用に限るデータは使わない。学習したモデルの使い道まで縛られるおそれがあるから。
- 公開データの版は固定する。

## v7 の事前学習

`configs/pretrain-v7.toml` に混ぜ方と理由があり、`configs/sources.toml` に各データの版とライセンスがある。日英は半々。

| 段階 | 読むトークン | 読み方 |
|---|---|---|
| パッチ段階 | 62.9億 | 4トークンずつ。各出典を質の点の低い順に読む |
| 安定期 | 12.6億 | 1トークンずつ。パッチ段階と同じ混ぜ方 |
| 減衰期 | 18.9億 | 1トークンずつ。質の高いデータ、推論、数学、コードに寄せる。学習率は後ろの7.5億で下げる |

v6 からの変更は4つ。

- パッチ段階と安定期の英語の Web で、FinePhrase を半分から1割に減らし、残りを v5 の FineWeb-Edu に戻した。
- ClimbLab-Ja の半分を、LLM-jp による日本語の Web の言い換え（CC BY 4.0）に替えた。
- 減衰期の FineWeb-Edu の上位を Ultra-FineWeb に替えた。
- パッチ段階で、各出典を質の点の低い順から高い順に読む。

## v7 の指示学習

`pretrain/instructions.py` に出典がある。v6 から、KUCI、JCommonsenseQA、JAQKET の学習用の問題に選択肢の記号だけで答える会話（約10万5千）を外した。評価の課題の練習になり、点を当て推量の率まで上げるだけで力を示さなかったから。

## 作り方

手順は `python -m pretrain recipe --config configs/pretrain-v7.toml --workdir data/pretrain-v7 --stage inspect` の `commands` に出る。CPU の多い機械で作り、R2 の `data/pretrain-v7/` に置く。v6 のコーパスは20プロセスで53分、16プロセスで61分かかり、どちらもバイト単位で同じものができた。指示学習のデータは6分で作れた。読み込みは約170GB（転送料からの推定）で、できるデータは約20GB。

`nemotron-v2-ja` は利用条件への同意が要るので、取得には同意したアカウントの Hugging Face のトークンが要る。
