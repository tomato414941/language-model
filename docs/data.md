# データ

## 決まり

- データセットの中身を細かくフィルタしない。除くのは、長さの範囲を外れる文書、同じ行を繰り返す文書、重複、評価の問題と、出典が持つ質の列の条件に合わない文書だけにする。
- 文書を繰り返して読まない。
- 非商用に限るデータは使っていない。使うかどうかは決めていない（`candidates.md`）。
- 公開データの版は固定する。

## v6 の事前学習

`configs/pretrain-v6.toml` に混ぜ方と理由があり、`configs/sources.toml` に各データの版とライセンスがある。日英は半々。

| 段階 | 読むトークン | 読み方 |
|---|---|---|
| パッチ段階 | 55.9億 | 4トークンずつ |
| 安定期 | 11.2億 | 1トークンずつ。パッチ段階と同じ混ぜ方 |
| 減衰期 | 16.8億 | 1トークンずつ。質の高いデータ、推論、数学、コードに寄せる |

v5 からの変更は3つ。

- 英語の Web を FinePhrase と DCLM に半分ずつにした。
- 減衰期の Cosmopedia を Nemotron の STEM の問いに替えた。
- トークナイザが数字を1桁ずつに分ける。

## v6 の指示学習

`pretrain/instructions.py` に出典がある。日本語38.9万会話、英語12.9万会話。v5 からの変更は、KUCI、JCommonsenseQA、JAQKET の学習用の問題を、選択肢の記号だけで答える形で足したこと。答えのトークンは日本語の学習対象の約0.3%。

## 作り方

CPU の多い機械で作り、R2 の `data/pretrain-v6/` に置く。20プロセスで、コーパスは53分、指示学習のデータは6分で作れた。読み込みは約170GB（転送料からの推定）で、できるデータは約18GB。

`nemotron-v2-ja` は利用条件への同意が要るので、取得には同意したアカウントの Hugging Face のトークンが要る。
